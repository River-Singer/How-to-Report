# 0.5.0：进度、表达与方法的完整计划交付

更新：2026-10-28。此版本承接0.4.0源码审查、MASTer视觉参考、单主标题偏好和10月28日增补，将计划A/B的实现放在同一版本交付。它是用户回归候选，不是正式V1准出或已证明的模型质量提升。

## 本轮解决的问题

普通进度备注与决定汇报方向的上下文过去共用接纳指纹；现在支持显式版本化决策上下文，旧记录保持原有解释。写入前统一检查自身及其他可识别Skill安装目录；同精确版本存在未处置的非通过检查时，语义节点不能仅凭另一条pass变成verified。处置理由仍须审阅，工具不会证明声明真实。

PagePlan0.2默认一个醒目主标题，语义问题与takeaway不再机械堆叠显示；必要条件由正文、图旁或对应限定承担。0.1保留原来可见内容，不能只换版本号就当迁移完成。视觉采用近白纸感、柔雾/轻颗粒与浅蓝柔光，克制半透明磨砂、薄边与柔影；无衬线黑灰正文，少量蓝色强调。内容重要性决定布局，不为填满页面而凑卡片。巨大淡化文字/数字仅为封面或转场的可选装饰，不能扭曲图表比例、遮挡证据或形成额外主标题；无模糊支持时仍可读，打印单独检查。浅色胶囊工具栏、页点、目录、全屏、可选讲稿、阅读全部和打印共用同一套界面；主线和按问题进入的Backup支持返回原位。

表达能力增加受控本地图片/视频、原图标注、显式关系/依赖/泳道和结构化表格。素材保留哈希和字节快照；视频需要poster，不自动播放，离页暂停。受控结构不接受任意用户HTML/SVG/JS。文件头检查不证明图片可解码或视频编码可播放，仍需真实浏览器检查。

项目进度使用独立的ScheduleSpec和确定性日期计算，业务任务不等于Agent工作任务。基线、实际、预测、状态日、执行与验收、工作量分母、历史预测及来源版本保持区分。可按资料条件生成管理摘要、跟踪甘特、里程碑对照、结果/验收矩阵、预测漂移，复用统一页面与回执。工具不自行重排项目，不提供关键路径、工作日历或资源平衡。

认知方法沿既有Graph接入四类按缺口动作：概念状态澄清、前提约束审查、条件交互分析、主张证据桥梁。诊断式问题应改变路线/证据/行动，候选路线须有实质差异；价值表达同时防遗漏与拔高。会议疑问预演、时长再编排、代表页粗排和整稿视觉编辑强调可观察变化，不靠方法名或自评分证明有效。

经验能力分开已确认偏好、任务案例和方法修订候选。显式外置保存、查询、修正与撤回保留历史；一次反馈不变成通用规则，案例不能覆盖当前事实，不自动收集跨任务资料或修改核心Skill。离线文字仍按来源正文/选段/原创摘要及实际许可范围标记，详见[离线资料](offline-knowledge.md)。

| 对象 | 本轮约定 |
|---|---|
