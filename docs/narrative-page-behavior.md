# 叙事、逐页内容与视觉表达的行为契约

更新：2026-10-28。0.4.0把下列检查接入现有方法与实际产物。它们是实现的工作要求，尚无新版模型行为效果结论；不是新增Agent平台、统一流水线或每页固定字段/图表数量。

先从已确认结果与受众形成Content Blueprint，再确定叙事路线、页面认知任务、视觉选择与空间布局；实际渲染后从成品反读核对。简单任务可在原稿/笔记直接完成，不强制每一步独立文件。按需核心方法完整随两个Skill提供，运行不依赖外部链接或联网检索。

| ID | 触发后必须做什么 | 证据与失败后的返回层 |
|---|---|---|
| N01 | 新建/重构路线时，由结果找必答模块，再由模块反查职责 | Blueprint双向对应与缺口；补证或改路线，核心目标由用户决定 |
| N02 | 只有实际策略分歧时比较起点、疑问、结尾、证据负担及取舍 | 少量实质路线对照；换名字的同一路线合并，不凑数量 |
| N03 | 串读关键判断、说明关键转接，从结尾反查支持 | 判断序列与支持引用；分别回到背景、证据或目标相关性修复 |
| P01 | 页面问题、期望理解、前置知识和支持先于布局 | 简短页面语义说明；任务不清就合并、拆分或重定义 |
| P02 | 核对事实/解释/推断/计划/限制/行动及讲稿的主张强度 | 内容角色、最小支持与缺口；补具体内容或降格，必要限定可见 |
| P03 | 删减/重构时交代重要内容去向，按引用复用共同事实 | 蓝图差异/处置记录；恢复必讲/限制、去重复并查受影响页面 |
| V01 | 选主要视觉前判断读者任务及相对文字/表格的理解增量 | 一句选择理由与内容引用；无增量就换表达，不用装饰充证据 |
| V02 | 对数据图核对象、单位、期间、基线、聚合、缺失与结论 | 数据/公式/图表规格；请求数据、改图或缩小结论，定性图仍可用 |
| S01 | 区分数据、关系、实物证据、装饰再选SVG实现 | 关系含义与实际比例/裁切/可访问文字；修模型或渲染，不伪造截图 |
| M01 | 多视图逐一绑定子问题/主张，再核跨图口径和数据状态 | 视图对应与上下文；统一/明示差异、拆页或删无增量组件 |
| L01 | 使用真实长标题/标签/来源/限制粗排并判断容量可读性 | 实际粗排/尺寸/截图；重分空间、删冗余、换表达、分层或拆页 |
| L02 | 实际激活每页及重要支持状态，就绪后测量并查看内部标签 | 浏览器/窗口/指纹/原始输出/截图；修复后重查受影响页和状态 |
| A01 | 查视觉是否抢夺注意力，也查必要关系是否表达不足 | 截图与组件去除后的意义变化；重设强调/分组/关系，不按面积配额 |
| A02 | 审计先仅看成品复述意义与确定程度，再看计划/原资料 | 先反读记录与真实暴露范围；回到计划、图形、可读性或原结论层 |
| R01 | 修改锁定授权范围，沿真实引用检查相关计算/图表/标题/结论 | 变更与影响清单、版本和重测；重大目标重查路线，间距不扩业务范围 |

检查不能退化为表格填写：例如N03发现结尾无证据，必须补证、降格或改结尾；M01发现图表对象不同，必须修正联合结论或明确差异；L01发现关键限制装不下，不能删掉限制换取几何通过。每次保留实际动作与尚未解决的问题，修复从最早出错层开始。

两期数据允许表达变化，不能自动宣布持续趋势；单期数值不产生历史曲线。定量分解不自动构成因果，未知值不补零，图形/箭头/色彩不增加未经支持的收益或闭环。页面空间关系、来源声明、程序几何与业务证据是不同层次。普通正文/表格保留可读文字，复杂图形须有关键含义的文字说明。

行为记录可在Markdown标pass、fail、blocked、not_assessable、not_applicable；不适用有理由，未评估不计通过。基础Run Check仍仅允许not_run/pass/fail/not_assessable，blocked属于工作阻断，不适用保存在范围说明中。这次没有通过新增JSON字段或机器pass制造语义保证。

实现入口是生成侧的[方法](../skills/how-to-report/references/reporting-method.md)、[HTML计划与工具](../skills/how-to-report/references/report-html.md)，以及审计侧的[实际页面检查](../skills/report-audit/references/page-audit.md)。两包均携带完整[行为方法](../skills/how-to-report/references/narrative-page-behavior.md)。来源研究留在开发期归档；这份公开说明及随包方法已包含运行所需规则。

本地预备的14项变形测试为B-N01/N02、B-P01/P02、B-V01/V02、B-S01、B-M01、B-L01/L02、B-A01/A02、B-R01、B-G01，分别针对目标变更、结尾支持、内容关系、局部范围、单期/两期数值、反馈关系、跨图口径、长内容/隐藏页、组件删减/视觉暗示、基线更新和无浏览器。输入、阶段变化及评审关注分开；全部是明确合成探针，不当作MASTer真实事实或未见Holdout。尚未执行，不填预期模型答案，也不按唯一截图验收。

当前先提交产品与已冻结要求，供GPT审计；模型测试包是随后可执行的准备，仍由用户决定运行并交付结果。正式B0/B1/B2须另行控制模型、输入、工具、预算与额外调用成本。工程回归只能验证对应确定性规则，不能证明叙事判断、语义往返或审美效果已改善。
