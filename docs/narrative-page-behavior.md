# 叙事与内容的可观察检查

0.6.0以当前沟通任务决定检查，不要求填写旧15条页面表。原视觉检查属于历史范围；当前不生成页面或要求浏览器。

- 主线从已确认结果反查：重要目标由什么内容回答，各部分为何属于这次汇报。
- 仅在实际存在策略分歧时比较路线，不为了展示方法凑多个模型名。
- 串读核心判断，检查必要背景、证据与推理是否接得上；结尾不能突然增加未经支持的结论。
- 内容先按共同回答的问题分组。该一起比较的信息不要按文件或数据类型拆开；短任务可以不分页。
- 正文站在真实汇报者立场直接表达，制作安排和核验记录另置。重要条件贴近主张，但不把每段写成审计免责声明。
- 修订沿实际影响检查数字、状态、归因、条件与请求；局部措辞授权不等于可改整个目标。
- 独立审计先读成稿，记录读到的判断与行动，再对照要求和资料。模型复述是筛查，不代表真人理解。

发现缺口后改正文、补证据或调整判断；不能以“已检查、逻辑清晰”替代动作。不同的合理结构和措辞可以通过，依据是沟通责任和事实忠实，不是模板相似度。

结构化长材料时，按意思和共同问题识别、分组与排序。明确区分原文明示、可支持推断、未知与冲突关系；时序不自动变成因果，影响不自动变成唯一前置，并列不自动变成排名。局部关系和全篇叙事分别选择，写完反向核对重要信息和关系。它是现有成稿的一项按需动作，不是新增结构化引擎或强制字段。
