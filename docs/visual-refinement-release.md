# 0.5.2 观众成稿与视觉整改候选

日期：2026-10-30。0.5.0 实际生成稿暴露了说明文字压过重点、图形被压小、卡片遮挡和并行/反馈关系被误读的问题。0.5.1 已调整观众稿编辑方法、显示默认和关系布局；用户复核开发预览后，又指出抽象措辞、过度概括和审计式旁白妨碍阅读。0.5.2 在这份工程基线上补强成稿规则，原0.5.1冻结包及检查记录保留。几何检查不能证明文案或语义正确，原记录不改标为新版通过。

本轮用户确认的设计要求：

> avoid unnecessary secondary labels and descriptions. Let the layout do the explanation

## 0.5.2 成稿增补

在已有[观众成稿方法](../skill-src/shared/references/audience-copy.md)里加入具体编辑动作：从材料恢复对象、动作和关系；保留有用的分工与用途；一句混放不同话题时重新组织；按受众和场合通读后，再核对事实、否定、状态、条件和归因。生成与独立审计入口均可按需读取，渲染器继续忠实装配作者提供的文案。

审计同时检查“添加了什么”和“有用信息是否被写空”。事实被缩成“采用合适的方式”也可能不合格。重要条件仍贴近对应判断；制作过程和与本页任务无关的核验旁白回到相关记录，不能为简洁而删除影响判断的边界。

自然表达服从文体与实际问题，不强制口语、第一人称、固定短句或禁词表。没有问题的句子可保留，不新增必跑Humanizer角色或强制二次模型调用。正文附三个完整合成材料对照，分别说明分工具体化、未知安排和数字/测试范围保真；它们是教学例，不是模型测试成绩。

## 0.5.1 显示与关系布局基线

- 在两个独立入口按需加载自足的[观众成稿方法](../skill-src/shared/references/audience-copy.md)：沿用已确认目标，按共同问题分组，提炼有依据的判断，写主体/动作/条件，先读纯文字再装配。制作说明、实际讲稿与证据记录分开；不增加Agent、固定三点或字数硬阈值。
- PagePlan0.2 的组合元素可省略没有职责的title/body；提供的文案仍忠实显示。text至少有标题或正文，metric保留数值对象标题。普通兼容布局和PagePlan0.1要求保留；新稿仍需主动完成编辑，旧稿重渲染不会自动成为观众稿。
- 以页内短编号连接完整离线来源与图形文本替代，减少卡片、节点、边和页脚重复长定位。来源对话框、连续阅读详情、含来源打印各有真实访问路径。关键预测、批准、验收条件保持主面可见。详情是交付载荷，不是访问控制或自动脱敏。
- 关系图按显式有向边分层，同起点分支保持并列，反馈绕行；可选方向和作者提供的短边名适应表达。无方向关联不变成因果。有限节点图也须实际检查，不能宣称任意图自动清楚。
- 保护图形必要空间并检查实际SVG文字尺寸；过载需要编辑、重排或拆页，不用裁剪、极小字体或静默删条件消除告警。

详细字段与边界以[随包HTML说明](../skill-src/how-to-report/references/report-html.md)和实际实现为准。Run0.1、PagePlan0.2、独立离线双包与原有证据状态不变。全篇双语、直接编辑、自动播放和任意复杂图优化不在本次新增范围。

## 验证与测试交接

0.5.1的工程结果见[历史验证](../verification/0.5.1/README.md)，其通过范围不包括0.5.2新增的成稿行为。0.5.2需检查源文件与两包一致性、离线说明与许可闭包，并对实际修改的预览重新验版。具体命令、包身份和结果以对应版本的验证记录为准；方法写入包内不代表模型执行通过，也不证明真人已经理解。

[0.5.1的16项设计](../evaluation/release051-cases.jsonl)使用重新编写的合成材料，覆盖12项观众稿/局部修改问题和4项分支、反馈、容量、来源交互。沿用逐阶段释放工具；全部为开发者已见Dev输入，尚未执行模型。原51项设计保留，合计67项。0.5.2用户交接另关注具体分工是否保留、句子是否说清待办、审计语气是否放错位置、改顺后有无事实漂移。

浏览器检查至少覆盖有代表性的请求页、并行/反馈页、拥挤图表页和稀疏页；核实际截图中的重点和关系，另核来源可达、键盘焦点、阅读/打印。程序结果、截图观察、模型反读与真人理解分别报告。批量模型生成/审计/修订由用户执行；旧冻结包与用户输出作为历史对照保留。

## 依据与归属

运行方法已经自足，使用者不需要这些私有研究包或联网读外部链接。没有把外部服务的默认数据补造、固定字数或全部提示词照搬为本产品规则。原有离线知识档案与许可范围保持原合同。
