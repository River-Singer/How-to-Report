# 当前审核候选的实施与验证边界

更新：2026-10-28；当前0.4.0尚为首次公开审核候选。进度以[冻结需求逐项状态](requirements-freeze.md)为准，不再沿用早期40–50%的范围估算，也不把新增工具或通过测试数换成精确完成比例。

| 已确认范围 | 当前可查实现 | 仍需什么证据 |
|---|---|---|
| FR-01/02/07/14/16：可见工作、来源、版本与接纳 | 独立Run、实际快照、显式版本与依赖、检查绑定接纳 | 实际宿主持续使用、依赖与正文一致性及受影响修订的模型记录；不承诺后台任务平台 |
| FR-03–08/13及新增认知/叙事行为 | 目标发现、解释探索、Blueprint、15项适用行为检查与镜像审计 | 陌生材料下的稳定性、遗漏、过度推断与真实语义反读；方法已写不等于效果通过 |
| FR-09：计算 | 显式规格、受限操作与真实结果/来源凭证的本地适配 | 独立数值oracle和工程检查；业务口径/因果仍需材料判断 |
| FR-10–12：页面与视觉 | 递归主辅组合、文本/层级/指标、条形/折线/矩阵、有界画布、浏览器几何与输出映射 | 最终字节的实际多页/状态/画布检查，以及模型从材料到页面的质量；工程样例不是用户效果样例 |
| FR-15：评测 | 仓库内[评测维护源](../evaluation/README.md)：25例/7原fixture、必要补件、14变形例、协议、只读校验与独立oracle | 用户执行真实B0/B1/B2、未见集和独立评审；当前输入已读，不能当Holdout |
| FR-22及离线/许可约束 | 已确认画像的私有保存/查看/修订路径；核心方法与Knowledge来源离线可用 | 实际用户确认和宿主授权不由辅助工具认证；跨任务自动画像仍后置 |

本轮交付顺序是完成冻结范围内实现及工程检查，提交并推送可审计仓库，供GPT先检查需求、方法、代码和证据边界。[审计入口](audit-start-here.md)给出阅读路线。模型测试输入可预先冻结，但不要求用户先跑模型才允许代码审计。

模型大批量生成/独立审计/按意见修订仍由用户执行；开发侧准备输入、版本、提示和输出位置，收到结果后复核。实际工程验证范围以[本版说明](html-runtime-release.md)与公开验证记录为准；递归扩展前153项/browser01只保留为旧基线。

正式V1准出还需要同条件模型比较、真正未见材料、实际声明支持宿主的记录和风险闭环。未测试云端持久性、原生安装发现或模型质量不能写成已支持/已改善。全行业百科、完整Office引擎、所有图库、跨任务自动画像与通用后台调度不因本次进度盘点变成新的核心要求。
