# 当前实施与验证边界

更新：2026-11-02。0.7.1针对已交0.7.0案例暴露的编辑和审计问题进行优化，具体范围见[开发计划](development-plan.md)。不按版本号、文件数或缺陷数计算完成百分比。

| 范围 | 保留的能力 | 本轮需要验证 |
|---|---|---|
| 生成主线 | 任务→材料提炼/判断→叙事/逐页成稿→自查，按需进入 | 具体业务关系是否比分类堆积更清楚 |
| 持续修订 | 当前方案和约定继承，局部回退 | 新证据是否真正改变判断与安排 |
| 材料交付 | 明确页数、页序、每页可用文字 | 标题与正文是否分工，局部改动是否守范围 |
| 独立审计 | 先正文后来源，复核问题与改写 | 是否纠正自己的误读，修复是否避免新事实 |
| 可靠性与离线 | 工具契约、两包自足、本地来源 | 工程检查与宿主实际取用分别验证 |
| 视觉 | 已退出生成与验收 | 不作为本版门槛 |

0.7.0案例已有结果，但发现内容取舍、预测依据和审计修复问题，不能认定全面优于旧版；运行记录也不足以证明原计划的同会话连续能力。旧[工程记录](../verification/0.7.0/README.md)仍只属于旧包。
