# 0.11.0 自有参数模板与PPT制作技术

本轮提炼PPT-Master的制作技术与方法，将完整外部入口改接生成包内的实际检查和原生导出。正式模板资产来自用户参考资料，统一纯白16∶9画布、标题与页眉页脚几何，内容/config参数化，提供variants、tokens及逐模板AI使用说明。

工程检查覆盖技术闭包搬迁、来源与素材排除、实际测量helpers、输入变化后的检查失效、完整Theme注入与回读。模板检查覆盖参数、文本长度、tokens、结构合同及全部实际variant的渲染调试。成品视觉、目标宿主编辑、独立内容审计和真人理解各保存真实范围。

后续实际汇报与模板复用使用用户指定的飞书使用情况DOCX，面向IT部门领导。原成本单例按用户切换要求收口，历史检查继续绑定原产物。常规工程单元与结构检查按实现需要执行，批量模型案例继续由用户运行。

以下记录既有版本的原范围。

## 0.10.1 挑战目标聚焦与验证计划

本轮围绕挑战问题如何影响汇报目标补强选择、接纳与停止操作。挑战者从本场必要认识、判断或行动追到当前主张和前提，检验异议成立后的实际后果，结合其他充分依据及已明示条件选择最强路径。本场阶段与当前主张强度共同确定证明责任，真正决定当前目标的细节继续深入。

主代理同样核目标影响、问题自身的前提、专业规则适用域和新增门槛依据，保留有范围的明确观察与有效阶段性回答。复查先核修订后原阻断是否仍存在，新增疑点也经目标影响检验，共享前提统一分析。集中方法为[定向挑战](../skills/how-to-report/references/directed-challenge.md)，真实委派与仅问句契约按现有主线执行。

工程检查验证两包资源闭包、共同方法一致性和搬迁。语义回归应覆盖同一细节在经验交流、正式承诺和核心误类比中的不同作用，以及收窄后的撤回、独立阻断保留与来源观察保真。实际问题质量根据后续模型结果及可得原始轨迹评估。

## 0.10.0 总入口 PPT 接续基线

用户向完整套件总入口提出制作 PPT 的请求，内容工作沿现有主线完成。实际确认当前内容后，总入口连续接续可用的完整 PPT-Master，沿其正式路由完成制作、检查与导出。外部 Skill 由宿主能力或实际提供的入口定位，内容交接方法随生成包提供。

工程验证覆盖总入口与两包的资源闭包、整体及单包搬迁、内容确认与外部制作职责的规则一致性。实际连续接续、生成质量和目标宿主编辑由用户单例测试记录建立。

首轮采用四份已有合成成本试点资料，五分钟业务试用判断。准备冻结总入口、保持相对目录结构的两个完整包、独立完整 PPT-Master、输入与自然任务提示词，输出位置供用户运行时追加。操作者验收标准单独提供。

用户返回首轮结果后，对实际内容、确认、工具记录和 PPTX 做复核，按具体失败修复。联通取得可验收结果后，使用用户现有模板提炼可复用规则与工作区，先用同稿观察模板引入的影响，再以不同内容验证复用性。

## 0.9.1 既有内容能力与验证基线

本轮保持A/B/C/D和Markdown交付，补强可复算计算与最终推荐、来源含义以及多轮更新后的正文收敛。Run0.1不变，计算Spec0.1兼容，Spec0.2增加有符号差额和人时换算。沿用真实利益相关者确认、仅问句定向挑战、具体求助和分阶段独立审计，不增设新角色或必交台账。

方法库按判断问题选择，费用、资源与技术数据方法和市场、产品营销、销售、公关方法共同支持实际分析。本人价值表达从受众需要、真实判断/行动与合作归属构思，不能只有夸大禁令；用户否认个人目的后停止沿用。知识方法不能填补未知项目事实。

[本版输入](../evaluation/content-0.9.1/README.md)沿用上一版18组41轮的全部自然任务、事实字节和分轮暴露。重点复核数值能否贯通推荐、来源含义、多轮反证与余项期限、以及挑战后是否形成面向听众的有用正文。旧批次和产物不变，参考判据不进入生成上下文。

发布顺序是源码稳定→构建两包→检查包闭包/离线来源/常规测试/输入隔离→独立检查修复→必要的重建重验→冻结最终用户批次。冻结后不能静默改变包。工程测试覆盖实际结构、路径、映射、哈希、无覆盖及来源隔离，不用关键词或方法名证明语义行为。

实际结果见[0.9.1工程记录](../verification/0.9.1/README.md)。运行者分别记录真实dispatch/return、角色来源、上下文分批暴露、实际工具权限与原始返回路径，以及计算输入、结果、回放位置；包身份不证明实际加载，Run声明不证明真实Agent身份。确定未执行写not_run，缺证据写unknown，自述与轨迹冲突保留两端。

模型测试全由用户执行，当前不启动本机Claude、API或子代理批量生成/审计。18组41轮是已知回归和新合成探针，不是独立保留集或受控效果实验；工程通过不能证明模型行为改善。
