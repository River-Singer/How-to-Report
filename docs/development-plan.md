# 0.8.4 开发与验证计划

V11的13组25轮已复核。实例解释、月份判断和审计更正有有效进展，但仍会把缺资料写成没做，将核查结果挪到其他版本，或为推荐补出窗口与收益保证。收到部分回复后，未完请求还会退到备查。原产物保留，本轮修实际处理过程，不另建一套提示词清单。

A/B/C/D继续负责目标、判断、表达和成稿检查。先确认实际采用的判断和理由由什么记录支持，沿实例展开时核新增加的关系，再修当前稿及受影响的讲解、备查和作者说明。局部改字不重做全文；来源核准也不删除已有用途或把每页改成免责声明。

同时将可选输入机会接入原工作流：当前有据内容先交付，说明补哪项最小记录能改变哪段解释或比较。后续资料可支持、反驳或只部分支持构想；按实际信息改稿，不只追加附件。没有有用机会、用户不补或只局改时，不例行索取。当前主张所必需的依据仍要先处理，不能藏到可选建议中。

[本版输入](../evaluation/content-0.8.4/README.md)保持原13类场景和25轮请求/曝光，再加4轮：03支持实例、06反证、08部分迁移样本、07明确不补。03前两轮仍作同源短稿与阅读对照，04保留联合评审，05保留仅改标题，09—13保留进度、周期、迁移和审计回归。旧事实字节不变，新材料只在新增轮开放；评审参照与未来资料不能给生成者。

交接前检查源码与两包同步、离线链接、适用工程测试、输入隔离和冻结完整性。实际工程状态见[0.8.4记录](../verification/0.8.4/README.md)。完整包哈希不证明实际加载、连续会话或审计独立；正文与运行记录冲突时记录两端，未核留unknown，实际未执行留not_run。

模型测试仍由用户运行。没有匹配重复样本或真人试读支持总体提升率；本版只是有待验证的方法优化。Run0.1与工具算法保持，视觉制作留给下游。
