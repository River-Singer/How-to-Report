# 0.7.0 开发与验证计划

本版把近期研究和案例问题收敛为一个生成主工作流与一个独立审计主工作流。生成依次解决当前尚未解决的任务理解、材料归并与判断、叙事及逐页成稿、实际含义核对；短任务可直接进入，专题只负责具体难点。

实施包括：原位置重写主方法；材料提炼与自然表达职责收窄；叙事内容并入会议表达，退役重复方法；用连续合成示例解释具体取舍；同步两包、离线资料与文档。数值、日期、Run0.1、版本和写边界工具保持兼容，历史输入与结果不变。

工程检查后准备[四案评测](../evaluation/content-0.7.0/README.md)。前两案用冻结0.6.1与0.7.0匹配输入、同模型和工具条件，各组在同一会话逐轮修订；后两案仅新版定向，共六组。只准备输入与提示词，不自动执行模型。生成不能提前看后续轮次或审阅标准；独立审计先读取实际正文。

模型结果将回答：是否按共同问题归并而不是复述材料；目标或听众改变是否改变内容；是否给出实际页数与全部逐页成稿；新事实、压缩与局部修订是否保真；审计是否减少误报且能发现实质错误。没有统一标准标题、页数或隐藏动机答案。

[本轮工程复核](../verification/0.7.0/README.md)已完成，模型效果仍待用户交付。没有新的失效线索不扩测，不把文件更少、提示更短或结构更齐整本身当作成功。
