# 0.9.0 开发与验证计划

本轮保持A/B/C/D和Markdown交付，增加真实利益相关者门槛、真实子Agent定向挑战、主Agent先读算后具体求助，以及分阶段独立审计。挑战者只返回基于本次目的、职责和事实的问题，主Agent自行回应和修订；没有对应能力时明确未执行。Run0.1和既有工具算法不变。

方法库按判断问题选择，费用、资源与技术数据方法和市场、产品营销、销售、公关方法共同支持实际分析。本人价值表达从受众需要、真实判断/行动与合作归属构思，不能只有夸大禁令；用户否认个人目的后停止沿用。知识方法不能填补未知项目事实。

[本版输入](../evaluation/content-0.9.0/README.md)为18组41轮。保留原13类29轮任务覆盖，增加本场职责确认或澄清；新增双项目多角色4轮、市场→产品→营销3轮、销售2轮、公关1轮、本人价值→客观介绍2轮。旧来源字节保持；旧批次与产物不变。参考判据与未来材料不进入当前生成上下文，私有项目分支不进入公开仓库。

发布顺序是源码稳定→构建两包→检查包闭包/离线来源/常规测试/输入隔离→独立检查修复→必要的重建重验→冻结最终用户批次。冻结后不能静默改变包。工程测试覆盖实际结构、路径、映射、哈希、无覆盖及来源隔离，不用关键词或方法名证明语义行为。

实际结果见[0.9.0工程记录](../verification/0.9.0/README.md)。运行者分别记录真实dispatch/return、角色来源、上下文分批暴露、实际工具权限与返回路径；包身份不证明实际加载，Run声明不证明真实Agent身份。确定未执行写not_run，缺证据写unknown，自述与轨迹冲突保留两端。

模型测试全由用户执行，当前不启动本机Claude、API或子代理批量生成/审计。18组41轮是已知回归和新合成探针，不是独立保留集或受控效果实验；工程通过不能证明模型行为改善。
