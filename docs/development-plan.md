# 0.7.5 开发与验证计划

保留四项生成工作和独立审计。0.7.4用户结果有具体改善，也仍出现材料缺失被写成项目没做、可比费用被写成预算足够、原期限只留历史表、审计改级保留误报。没有宿主读取轨迹，不把某一规则断定为唯一原因。

- 用来源支持的对象、操作和结果解释业务用途。将正文中的作者提示和重复状态移出听众视线，给实际解释留篇幅；不强制同一种操作链或固定页数。
- 将新增判断对回原材料：费用组成相同不等于资金足够，没收到答复不等于事项未定。修正示例里的同类不一致，避免原则和示范相互冲突。
- 部分回复后检查最后交给听众执行的那项行动，实际保留未完成义务和期限；历史表中出现日期不能替代当前请求。追加建议与原余项分清。
- 审计撤回不成立指控后，当前清单和强制修法也应撤掉。范围/归属疑点独立判断，不能借缺一个同义标签延续误报；必要条件与可及性分别核。

[新评测](../evaluation/content-0.7.5/README.md)为13组23轮：内部AI实践比赛2、外部创新比赛1、业务一级2、业务二级1、技术一级2、技术二级1、总负责人2、外部同行1、项目进度3、周报2、月报1、培训迁移2、独立审计3。场景从既有受众覆盖恢复并扩展，不是首次发现这些任务；不同场合的目标、取舍和交付应真实不同。

周报和月报使用明确周期与对照的合成资料，包含一次计数更正和月末状态变化。周报交完整阅读稿，月报按本次五分钟评议交逐页方案，不把周报拼接当月度判断。09首轮留真实目标不确定性，确认后才交完整稿；05局部改真实末页标题；13按正文、来源、作者说明分阶段开放。

公开输入全部合成；私有项目交接保留在用户工作区。每组独立、组内持续会话，操作者保留原始输出、额外往返和可得宿主日志。只读输入校验不执行模型，不证明实际读取、内容效果或真人理解。没有匹配旧版、独立保留集或重复样本，不计算提升率。

不新增工作流阶段、常驻字段、渲染或数字算法；历史包、来源及结果保持原身份。[本版工程记录](../verification/0.7.5/README.md)与旧[0.7.4记录](../verification/0.7.4/README.md)分开。先完成方法和工程检查，再冻结已检查的版本，模型测试由用户运行。
