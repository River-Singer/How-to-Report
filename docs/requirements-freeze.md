## 1. 产品与运行边界

产品为两个可独立使用的 Skill：[生成入口](../skill-src/how-to-report/SKILL.md)与[审计入口](../skill-src/report-audit/SKILL.md)。双入口内部保留目标、假设、证据/论证/证明义务、任务、内容、叙事/页面与版本依赖的不同职责，见[多图模型](../skill-src/shared/references/graph-model.md)。它们不是固定十步流水线，也不是每种图一个 Agent。

正常入口是 create、revise、audit、analyze-first。简单文本任务可跳过复杂图、并行、计算和视觉；目标不明确时才作必要澄清；局部修改不重做无关工作。审计默认只读原件。主观策略归用户选择，事实强度归证据约束。知识许可不等于联网、外传、企业写回或代码执行授权。

宿主采用能力检测与诚实降级：[宿主能力](../skill-src/shared/references/host-capabilities.md)。本地隔离文件 Run 已有工具；云端只使用其实际提供的工作区并披露持久性，无文件/计算/浏览器/独立上下文时明确未执行。没有承诺所有宿主能力一致，也不以本机包搬迁测试证明原生安装发现或云兼容。

记录包括对象/版本、实际状态、依据、缺陷影响、修复层与重查结果。Markdown可用 pass/fail/blocked/not_assessable/not_applicable；不适用须说明理由，未评估不能计通过。Run Check保持既有枚举，不能把blocked/not_applicable冒填成pass。新增14个B-*行为案例是评测准备，自动检查仅覆盖确定性部分，模型/独立评价由用户执行。

### Visual-Lab：恢复原本承诺的组合架构

空间组合不是四种整页卡片模板。冻结链路为内容/论证→页面语义→视觉意图与图表数据→有界递归布局树→renderer→runtime→镜像审计。至少用工程样例复现“层级+排序+时间变化共同观察”和“主矩阵/比较+辅助证据”；主辅权重、阅读顺序、清晰标题、浅蓝白底和克制强调来自原型参照，不能靠复制其过密标签来验收。

当前实现扩展为 row/column 相对权重树与 text/hierarchy/metric/chart 元素，以及 bar/line/heatmap；每叶唯一、映射完整、深度/节点有界，不接受任意CSS/HTML。线图缺失不插值连线，零值/负值/未知分开，所有真实数值来自输入，模拟值明确标注。默认1600×900集中为舞台配置，其他受支持画布有显式边界和真实测试；不能散落魔数或用“演示预设”撤销原PRD的可配置要求。

**本节扩展已实现，最终打包、完整单测与独立真实组合浏览器检查已通过；用户测试使用与这些证据一致的冻结Skill。** 未承诺自动求最优布局、所有12图种、媒体、双语切换、编辑保存或任意无限画布。
