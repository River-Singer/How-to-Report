# 项目进度能力（实现候选）

进度工具消费显式ScheduleSpec，通过统一PagePlan/Deck生成五类按条件使用的视图：管理摘要、计划—实际/预测甘特、里程碑对照、交付结果/验收矩阵、历史预测漂移。调用方法及边界见[运行说明](../skill-src/how-to-report/references/project-progress.md)，示例是显式合成输入，不对应MASTer真实数据。

确定性机制包括自然日日期计算、日终状态边界、批准基线与历史参照、执行/验收分离、百分比依据、有限FS完整性与循环检查、显式摘要选取、完整行动分页、图元来源映射与真实文件哈希。项目业务依赖与Agent工作前置不同；工具不会自动排程、填未知、选目标或认证业务结论。

同日FS不能凭日级资料确定先后，保留可见警告；早于前驱完成日的后继开始被拒绝。不同基线的历史不能直接连接；缺历史点不插值。无基线可显示现状，偏差保持未知。

HTML沿现有安全路径创建新外置输出，无覆盖、安装包写入或运行时网络依赖。原始输入、派生计划、页面映射和计算/渲染回执分开；所有语义、浏览器检查初始未运行。新结果的Run登记、接纳及变更后重查仍由版本机制和实际审计负责。

工程检查在`tests/test_report_schedule.py`。真实浏览器和最终包的验证由整版交付记录提供；方法效果由用户运行模型案例评估，不能用合成工程测试替代。
