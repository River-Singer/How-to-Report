# 项目进度：内容理解与事实核对

0.6.0保留进度事实能力，退出五类视图和页面生成。按听众本次需要，解释当前状态、变化、日期影响、尚未落实的条件或需要决定的事项；不自动把所有任务和统计口径铺进正文。

区分批准基线、实际发生、当前预测、执行状态和验收状态。完成局部清单不自动等于项目验收；时间经过比例不等于工作完成比例；缺少记录不等于事件未发生。真实能力与已完成工作可以直接说明，泛泛审计旁白不必逐项跟随。

按需使用[进度事实方法](../skill-src/how-to-report/references/project-progress.md)和日期校验工具。自然语言材料无需先改成JSON；结构化资料存在时可核对日期、基线身份、依赖和偏差。工具不自动选择目标、不生成新排期、不把预测改为承诺。没有基线时不捏造偏差，原日期和关键条件保持真实。
