# 0.4.0：组合页面、计算与画像的公开审核候选

更新：2026-10-28。当前0.4.0为公开审核候选，基础Run0.1、Knowledge0.1.1保持；页面计划有独立的0.1版本。

本版把 Blueprint/PagePlan 接到可实际打开的HTML。生成工具读取明确的本地计划，校验字段与引用形状，保存新目录中的自包含HTML、原计划、页面映射和生成回执。保留聚焦判断、并排比较、顺序解释与数值比较的简单计划，并增加有界递归组合：主辅面板可同屏安排文本、层级、指标、条形、折线和热力矩阵。布局描述空间和阅读顺序，不自动生成业务结论；提供导航、键盘、直接页链接、窗口适配及打印样式。画布默认1600×900，也支持明确有界的宽高配置，显示与打印共同采用。原始文字以文本处理；不执行其中脚本、不联网获取资源。

操作与字段入口见 [内容到HTML](../skills/how-to-report/references/report-html.md)。工程样例只用来验证功能，不能作为MASTer案例答案。真正的用户材料仍须先形成内容判断和蓝图，再选择布局。未取得数值不能补零；来源、限制和条件随相关判断显示。

视觉与分析构成参照项目早期 `How-to-Report-Visual-Lab` 原型：浅蓝白表面、清楚的标题层次和主辅面板；用层级、排序与趋势同屏回答相关问题，或以主矩阵配辅助证据。原型本身不作为运行依赖，也不照搬过密小字或裁切。此版没有迁入原型全部图表类型、媒体、语言切换、编辑或自动播放功能。

新增[叙事与页面行为](narrative-page-behavior.md)把N01–R01的15项检查接入已有蓝图、页面、渲染与审计，按触发执行实际动作和失败修复，不只填写字段；新版效果仍待模型验证。

本轮也补强现有认知方法的两个操作点：写大纲前检查候选结果是否改变证据/结构/结尾；发散方向用独立问题、区分观察和判断行动差异检验增量。既有目标发现与解释探索并非此前缺失，此次只是更明确地约束非引导澄清、主体/项目区别、反命题与新方向、相关指标、预算停止和未知边界。新增方法仍需模型探针验证。

本轮同时补齐[本地CSV计算](../skills/how-to-report/references/report-calculation.md)与[私有画像操作](../skills/how-to-report/references/report-profile.md)。计算对白名单操作保存输入、定义、单位、结果和可复跑凭证，拒绝缺值/重复粒度等错误；金额分解单列交互，不认证业务因果。画像只保存用户已确认条目的声明，支持显式查看和不可覆盖修订，保留历史；工具不认证确认消息、不自动跨任务采集，也不替代私有位置权限。

## 生成、浏览器与语义是三层证据

| 层次 | 能说明什么 | 不能说明什么 |
|---|---|---|
| 生成回执与映射 | 实际捕获的计划、输出文件及声明映射 | 没有执行的浏览器/事实/语义检查 |
| 实际浏览器操作、几何及截图 | 该HTML在记录的浏览器/窗口下的显示与交互 | 新报告自动适配、字段内容有依据、布局没有语义暗示 |
| 模型/人工反读与来源审计 | 本次读者可能理解的内容及其证据边界 | 通用模型增益或正式发布批准 |

独立审计先从实际页面反读，再看生成侧计划；规则见 [实际页面审计](../skills/report-audit/references/page-audit.md)。不能将反读前已经接触计划的会话标为完全独立。缺少真实浏览器时如实保留视觉未评估。

生成输出不自动注册为已接纳结果。继续使用 [版本与接纳](version-lifecycle-release.md) 登记实际产物和依赖，真实复核后保存准确版本的Check。来源/目标/范围改变须重新判断影响，旧页面与旧Check保留。纯几何通过不能替代内容复核。
