# 架构骨架验证记录

更新：2026-10-26。本轮使用当前 Codex 宿主、Windows 文件/执行工具与 Python 3.14.4。验证对象是包版本 0.1.0、Run 契约 0.1 的架构骨架。

## 包与契约

实际执行 `python tools/package_skills.py build`、`check` 及标准库测试。独立质量复核修复一处恢复缺陷后，最终 **39/39 项测试通过，无跳过**：17 项打包行为、22 项运行契约。

覆盖的行为包括：

- 两个包各自搬迁，不携带源码或另一个包，从无关工作目录运行实际校验器；共 8 次示例/变更查询调用通过。
- 检测共享资源漂移、缺失和多余文件；拒绝资源冲突、路径越界、链接/junction 与大小写碰撞；源校验失败保留旧包，模拟替换失败可回滚。
- 精确版本引用、布尔值等非法版本、重复身份/检查、未知契约、悬空引用和类型错误。
- `verified` 必须对应本对象版本的声明检查；Task 完成不能替代检查；任务前置循环拒绝、合法语义循环接受。
- 变更查询只沿 `uses` / `input_refs`；模拟多图例的数据变更影响 9 个依赖对象，独立背景支路不受影响。
- 许可 grant/read/revoke/re-grant 的声明序列；结构校验前后文件内容不变；外来文档无需生成图也可审计。

两包的格式检查使用 UTF-8 模式通过。外部格式检查器在 Windows 默认 GBK 下读中文失败，需要 `python -X utf8`；未修改该外部工具。Python 3.10 仅检查语法兼容，尚未在真实 3.10 解释器执行。

## 独立质量复核与实际调用

独立 Trellis 检查发现并修复了“替换失败、回滚删除也失败时，可能因目标目录仍存在而误清理旧包备份”的缺陷；新增双重失败注入回归。修复后重建两包，内容检查、格式检查与全部测试通过。6 个 Python 文件通过编译和 3.10 语法检查。项目没有独立 lint/typecheck 配置，未将缺少命令写成通过。

以下为实际按包路径调用的开发试用，创建与审计代理未继承父任务的设计/研究对话，只接收模拟用户请求、指定原始材料和包路径；后续修订沿用各自上下文。不是隐藏题，也不是质量对照实验。

|---|---|---|

六个上述 Run 均实际执行了包内结构校验，根代理最终逐个复查均接受。根代理还将审计三个输入与试用前 SHA-256 比较，全部不变，并将分析旧 Run 的 20 个路径/哈希与封存清单逐项比较，全部保持。画像记录可定位第 2 版的实际保存与重读位置，不从文件名自动推断业务现行版本。

创建试用记录了可选领域卡的拒绝，代理报告未读取，实际输出未包含测试卡标记。这里没有取得覆盖宿主全部文件访问的强制审计轨迹，因此不将自报日志或标记未出现当作“所有未授权读取均被阻止”的证明。

分析的独立复核先从原始数据用另一种实际方法计算，再查看生成结果。v1 复核使用新上下文；v2 复核沿用该复核历史，但未继承 v2 生成上下文。复核中发现背景文字混入了数据检查事实，而声明仅依赖背景来源；已修正该产物、同步引用并复查后封存，再开展 v2。结构校验本身没有发现这处语义依赖遗漏，后续开发验收已加入“声明依赖与实际内容一致”。

背景保持的是已封存的历史说明，其中原有“本轮未读第二份表”仅指 v1；v2 分析明确解释当前已获授权读取修订版，不将旧句子当成现状。

## 后续问题揭示的覆盖缺口

创建演练的请求一开始已明确给出“业务验收范围与参与人”目标。因此它验证的是沿明确目标组织内容、反馈修订及边界保持，**没有验证从模糊情境发现本次目标或潜在目标的能力**。六个Run也没有系统覆盖表示重构、解释基底删除/区分测试、跨领域交互与洞察遗漏。

在本记录对应的早期骨架验证时，新增的目标发现、解释探索和Knowledge仍处于设计阶段。后续方法与离线资料已随0.2.0/0.2.1实现，实际范围见[第一版结果](first-version-results.md)；这里的39项工程测试和六个Run仍不能转为新增能力的效果证明。正式质量对照尚未完成。

## 证据位置与结论边界

可重复执行的自动检查保存在仓库的 [tests](../tests/)；对应源码在 [tools](../tools/) 与 [skill-src](../skill-src/)。本轮详细命令、合成输入与实际输出保存在父工作区 `.trellis/tasks/10-25-how-to-report-skill-architecture/validation/`，不属于 Skill 的运行资源，也不是正式评测 Holdout。

包格式和按路径调用不证明宿主原生安装、自动发现或跨宿主兼容。Run 校验只检查可观察文件与声明的一致性，不证明事实真实性、许可消息可信、完整访问日志、独立审计质量或页面效果。没有执行生产 HTML、通用任务调度、自动重算或 B0/B1/B2 对照。

后续工作见[开发计划](development-plan.md)；未测能力应继续保持未测状态。
