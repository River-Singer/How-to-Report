# OR-03 组合选择、共享投入与依赖

版本：0.3.0。核对：2026-11-12。可选运筹卡；仅在有效许可覆盖本卡及相关来源时读取，不扩大既有授权。

## 判断问题与输入

多个项目应分开、组合、分期还是只选一部分；共同模块是否真能省资源。

必要输入：同一决策目标、真实候选范围、预算/人员/时间上限、共享与专用投入、互斥/先决关系、收益重叠和实际选择权。

## 实际操作

1. 列实际可选的组合及其条件：可同时、互斥、选A须先有B，分别有资料依据；不因项目名称相似认定重复。
2. 将共同能力的一次启动投入、项目适配和后续协调/维护拆开，核哪项共享确实替代原成本；收益按同一结果去重。
3. 在小范围实际枚举并复算候选总资源，先排除违反硬约束者，再按本次确认的目标比较效果、风险和机会成本。权重不由模型私定。
4. 区分材料合并、采购合并、技术复用和治理合并；核耦合、责任、迁移及延迟代价，结合关键假设说明何时改选。

## 产物、限制与停止

交回少量可行组合、舍弃理由和条件性选择；没有求解与完备搜索证据，不称全局最优。商业取舍仍由有权者决定。

共享范围、替代关系或约束未知时索取两项范围/接口及已有能力说明；先算已知部分，不能预先承诺合并省钱。

汇报人负责完成这些分析并组织为可理解的内容；挑战者用同一知识按真实职责检验最强的目标相关阻断，实质输出仅问句，不给答案或修法；独立审计核实际内容、来源与执行，不按方法名称判通过。角色与派发规则见[委派契约](../references/agent-delegation.md)。

## 短应用与误用

合成例：两项目可共用一项已验证能力，但一项必须先上线，另一项接口未定；可比较先独立接入、后复用与同步建设的真实差额。误用：公共模块成本按两次算后再宣称合并节约全部金额。 以上均为合成教学例，不是用户项目事实或固定问题模板。
