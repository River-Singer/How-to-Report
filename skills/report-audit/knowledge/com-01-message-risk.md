# COM-01 受众、消息与风险回应

版本：0.1.1。核对：2026-10-26。可选沟通公关轻量卡，仅在许可覆盖本卡时读取。

## 何时用、需要什么

用于多方关注、敏感问题、重要未知或对外消息表达。需要本次沟通目标、实际受众资料、可公开事实、限制与发言/决定权限。一般内部同步无需套危机传播流程。

## 执行动作

1. 根据实际问题识别受众及相关参与者：他们目前知道什么、误解或分歧在哪里、需要理解什么。头衔不证明偏好，更不证明隐藏动机。
2. 将核心消息逐条对应事实支持、重要限定和可能被追问的问题；承诺行动前核对权限、条件与是否已有安排。只有信息同步目标时不制造行动号召。
3. 对关键未知明确已知、未知和实际可行的核实方式；没有安排就不承诺日期或保证结果。压缩文字不得删除会改变风险判断的条件。
4. 用受众能理解的语言表达，再从实际稿件反读：读者会误以为确定了什么？不同参与者是否需要不同解释但共享相同事实？存在真实取舍时回到目标选择，不用话术掩盖矛盾。

## 交付与独立审计

交付消息—证据—限定的对应关系及必要 Q&A；可以提出可能遗漏的关切，不把关切假设当作对方意图。独立审计先从成稿重建读者会得到的判断，再对照原资料，检查过度保证、选择性省略及范围不明。

检查通过只表明本次稿件得到相应审查；没有受众反馈，不能声称他们已理解、信任或同意。停止于本次表达需要，不自行启动对外发布、媒体联络或真实危机行动。
