# PM-02 依赖、风险与决策事项

版本：0.1.1。核对：2026-10-26。可选项目管理卡，仅在许可覆盖本卡时读取。

## 何时用、需要什么

用于交付受外部条件、跨团队衔接或风险影响的汇报。需要目标、当前计划、已知条件、相关记录及实际权责；信息不全时明确未知。没有实质依赖问题，不为填图制造风险。

## 执行动作

1. 沿重要结果向前检查：什么条件必须在什么时候满足，由谁提供，证据是否显示已经具备。把项目交付依赖与 Agent 的调查任务前置分开。
2. 将未发生的不确定事件与已经发生的问题区分；用“什么原因可能触发什么事件、影响哪个目标”表达风险，保留依据和未知。没有数据时不编概率或红黄绿分数。
3. 联合检查条件：多个交付是否争用同一资源，接口或时间窗口是否不匹配，单项正常是否仍无法联合使用。必要时新增解释候选，而不是只给每个部门单列状态。
4. 对重要事项给出响应选项、需要的判断、责任权限和期限；实施响应之后仍检查剩余风险，不因“已安排措施”宣称风险消除。

## 交付与独立审计

输出少量有依据的依赖关系、风险/已发生问题、待核对条件及可执行请求。Task 只承接实际需要的调查；是否解除依赖由调查结果支持，不由 Task completed 决定。

审计检查被遗漏的共同条件、风险应对的副作用、已发生问题被写成遥远可能、以及请求是否发给有相应权责的人。没有完整网络、工期和资源依据，不能认证“关键路径”或保证交付日期。

当剩余未知已能以条件或明确请求呈现时停止扩图；不要把所有可能风险都变成必查阻断。
