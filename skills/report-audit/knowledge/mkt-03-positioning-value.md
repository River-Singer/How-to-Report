# MKT-03 相对替代的定位与价值证据

版本：0.3.0。核对：2026-11-12。可选产品营销卡；仅在有效许可覆盖本卡及相关来源时读取，不扩大既有授权。

## 判断问题与输入

客户为什么选择这项产品/服务，差异怎样变成他们在意的价值。

必要输入：目标使用者与购买者、其实际替代/原做法、已验证差异能力、使用情境、价值证据、交付与承诺范围。

## 实际操作

1. 从客户真实可选行动定位比较背景，包括原有做法或不买；不是只列同名竞品，也不虚构竞争者缺陷。
2. 将差异能力连到具体工作变化，再连到该人群在意的结果；逐连接核观察、机制、假设和条件。功能多不自动更有价值。
3. 选择最适合这些价值的人群及便于理解的类别，核类别会引发哪些能力预期；不要为响亮标签补造产品能力。
4. 形成有证据的价值主张和必要解释，核对演示、试用、服务及承诺覆盖；没有客户证据时保持待验证定位。

## 产物、限制与停止

交回特定人群相对真实替代的选择理由及条件，可直接写入提案；定位是有待检验的判断，不是唯一卖点口号或成交保证。

差异价值缺证时先要相关客户任务/替代记录或已做试用，不要求用户重写营销战略。用户只需技术客观说明时不强加销售定位。

汇报人负责完成这些分析并组织为可理解的内容；挑战者用同一知识按真实职责检验最强的目标相关阻断，实质输出仅问句，不给答案或修法；独立审计核实际内容、来源与执行，不按方法名称判通过。角色与派发规则见[委派契约](../references/agent-delegation.md)。

## 短应用与误用

合成例：工具能回到原记录，对需要复核的人可解释为减少寻找路径；未测工时不说“节省80%”。误用：把“AI赋能”本身当客户选择理由，或虚称所有替代都不能做。 以上均为合成教学例，不是用户项目事实或固定问题模板。
