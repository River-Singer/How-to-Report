# 计算说明（可选）

仅保留本次需要的项目；简单计算可直接写在正文。此模板没有执行计算，不是检查通过记录。不要填写未实际取得的来源、输出或哈希。

## 声明与范围

- 目标产物/对象及版本、位置：
- 原始数值声明与要检查的问题：
- 数值性质（测量 / 模型推算 / 计划预算 / 目标）：
- 本次检查范围与未检查部分：

## 输入与定义

- 实际来源、版本、数据/文本区域及定位：
- 单位、分母、包含/排除项和必要假设：
- 文本规则（仅需要时填写：空白、标点、外文、数字、代码或加权方式）：
- 公式、精度、舍入规则（含相关半值处理）及层级：
- 条件/阈值原句及其含义（充分条件 / 必要条件 / 精确边界，仅需要时填写）：
- 缺失的定义或输入及其影响：

## 实际核对

- 方法与状态（未运行 / 人工核算 / 作者脚本重跑 / 独立实现 / 实测；可按检查项分别记录）：
- 实际采用的输入与方法/脚本版本、执行时间与环境（如确有执行）：
- 可复核输入、中间量与结果位置（人工核算可直接写公式和结果）：
- 执行原始结果位置与保留范围、实际执行状态（确有执行时填写；未保留则明示，摘录不称完整 stdout）：
- 整理分析位置、所用原始结果及变换（如分组/删字段/重新舍入；与原样输出分开标明，无则省略）：
- 声明结果、核对结果、所比较的两个量、差值和影响：
- 当前结论与限制（相容规则能复现不唯一证明历史方法；计算一致不代表模型适用或现实效果）：

## 变化记录（如适用）

- 新增/修正材料、提供来源与收到时间：
- 本次重查动作、当前结果及仍缺什么：
- 历史说明/检查位置与旧版本适用范围：

使用 Run 时，将上述实际证据接到对应 Source/Artifact 与 Check；不要用模板文本替代实际检查，也不必新增 Run 字段。
