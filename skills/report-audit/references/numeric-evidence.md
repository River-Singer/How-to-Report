# 数值声明与复算

涉及会影响判断的数量、比例、比较、估时或阈值时读取。只做一句简单算术时，可在正文留下必要口径；复杂或有争议时使用可选的 [计算说明](../assets/review/calculation-note.md)。这是一份公开方法与结果记录，不要求保存私有推理过程，也不是通用计算器。

## 先确定算的是什么

绑定实际声明、对象版本和位置，区分测量值、按模型推算、计划预算与未来目标。写清要核对的是输入、计算、模型适用性，还是现实效果；这些问题不能互相替代。

在现有材料中找作者声明的口径及修正，按需确定：

- 数据版本、时间范围、对象集合、分母、单位、换算和排除项；哪些值是已知输入，哪些只是当前假设。
- 取数或取文本的区域：正文、标题、脚注、附录、备注等是否计入；不要在不同区域之间比较总量。
- 涉及文本计数时，说明空白、标点、数字、连续外文、代码等如何计数，是否使用加权或 token 规则。计数规则是本次模型的定义，不是通用朗读速度或语言规律。
- 使用的公式、舍入方式、精度和舍入层级：逐项舍入后相加，还是先求和再舍入；恰在半值时如何取舍，显示值是否只是近似值。

只要求会改变结论的定义。作者没有提供某项口径时，先定位已给附件或请求最小补充；可给明确标作替代假设的敏感性计算，但不能把不同口径的差值直接判成作者算错。定义缺失也不妨碍检查现有表内明显的加总、单位或自相矛盾问题。

## 按相同输入和规则复算

1. 保留实际采用的输入与出处；必要时保留可复算的小表或文本片段。不要以记忆中的旧值替代当前版本。
2. 按声明规则检查公式、单位和舍入；对比声明结果与复算结果，写明相减的两个量、实际差值及影响。发现错误应定位到输入、步骤或表格行，而非只报“不可复现”。
3. 区分取得作者方法、运行作者脚本、独立实现同一方法、人工复核和现实测量。重跑同一错误脚本可能得到相同结果；独立实现也需要核对同一口径。取得脚本不等于已执行，无需为复算直接运行来源不明的代码。
4. 记录实际执行方式、采用的输入与方法/脚本版本、输出位置及限制。有执行工具时只记真实运行；无工具时可人工核算可完成的部分，其他项保留未运行或无法判断。

分段估时尤其要区分模型值与安排值。例如两个分段各算出 4.4 秒，均按四舍五入到整数秒：逐段舍入后相加为 8 秒，先求和再舍入为 9 秒。两个结果相差 1 秒；原始 8.8 秒到 9 秒的 0.2 秒是另一种差值。先确定声明的舍入层级，不能挑最接近结果的规则。

“四舍五入”还需与实际实现一致：正数 6.5 按半值向上到整数为 7，按半值取偶为 6；不能假定语言或工具默认的 round 就是前者。只在会影响结论时明确并核对半值规则，不把示例规则强加给所有任务。找到一种规则能复现结果，只说明它与结果相容，不唯一证明作者历史上采用了它。事后补充的方法需注明来源与取得时间。

## 保留执行结果，另写整理说明

以工具执行作为证据时，保存实际返回的结果及其输入/方法版本，记录可取得的执行状态和限制。称“完整原样 stdout”就保留完整原文；只保留部分时标为摘录并说明范围。人工核算直接留下公式、输入和结果即可，不必造脚本或 stdout。

重新排版、删字段、分组、汇总或重新舍入后的表格是**整理分析**：与原始输出分开标明，指回所用结果并说明变换，不能仍称原样。可以用同一文件的不同章节，无需固定文件名。交付前核对声称的输出字段、分段方式、关键数字和舍入与所交方法/脚本是否对应，分析中的差值也要按写出的两个量复核。

原始结果没保留或与当前脚本不符时，如实保留这个证据缺口；不要按预期表格重造历史 stdout，也不能只凭不符就断言过去没执行。当前独立计算可以另行支持数字结论，却不能补成过去的执行凭证。修改方法后若重新执行，保留为本次新结果，说明旧结论怎样受影响。

## 阈值与方向

先把原句写成可核对的条件，保留“只要”“只有”“约”“至少”等限定，区分充分条件、必要条件和精确边界。不要替作者添加逆命题。

例如在固定字数 N、恒定速率 r、另加停顿 p 的模型中，时长 T = N/r + p。须注明 N 与 r 的配套单位、r > 0、p ≥ 0。要使 T ≤ L，若 L > p，则 r ≥ N/(L-p)；若 L ≤ p 且 N > 0，此模型下无可行速率。

“速率低于某个更低值就超时”可以是成立的充分条件，即使它没有给出完整边界。只有原句声称该值是精确阈值、必要条件，或作出不成立的保证时，才据此判错。考虑停顿、切页等额外耗时后，原先不含它们的预算不能冒充实际演讲测量。

## 得出有边界的结论

| 证据情况 | 可以得出的结论 |
|---|---|
| 同版本、同口径复算一致 | 指定模型内计算一致；仍需另查输入真实性、模型适用性或实际效果 |
| 同口径出现确定的计算、单位、集合或条件错误 | 指明错误及影响；修复建议不能冒充已执行修复 |
| 关键定义或输入缺失 | 该项暂不能判断；注明缺口和最小补证，不能写成实际错误或默认通过 |
| 方法已知但未实际检查 | 记录未运行；不能以“方法可复算”代替“本次已复算” |
| 只有估计、预算或模拟 | 按其真实类别交付；不能声明实际运行、测量、听众反应或达到目标 |

若使用 Run，将输入登记为 Source、说明/输出按实际需要登记为 Artifact，精确版本依赖放在 `uses`；Check 绑定被检查对象及版本，在 `method`、`scope` 和详情中记录本次真实动作。补证或修订后更新当前判断，保留旧检查适用范围；详见 [工作区契约](workspace-contract.md) 与 [证据交接](evidence-handoff.md)。结构校验不会执行上述复算。
