A constrained set of named visual choices can keep typography, spacing and color coherent. Tokens should express a chosen design system and remain compatible with real content. They are not evidence for a universal minimum font or a requirement to make every page identical. Source: U.S. Web Design System, https://designsystem.digital.gov/design-tokens/ . Original summary.
