# 主张、依据与推理桥梁

- **触发**：材料罗列后难以形成判断，或功能/投入/方法被直接升级成成效、价值、因果和承诺。
- **动作**：明确当前主张、支持材料及从材料到主张不可缺的连接条件。区分条件、做法、产物、观察结果和意义。提出最能区分替代解释的一项观察，检查相反证据及适用范围；不机械填六个框。
- **可观察结果**：保留改前/改后的完整判断、原来源定位，以及具体修复了哪条关系。价值探索同时问“它可能帮助谁作什么判断/行动”和“现有材料支持到哪层”；既不漏掉有根据的用途，也不将用途变成实现金额或工时。
- **回落与停止**：证据不足时选择有限主张、显式条件或具体补件，不为收尾漂亮增加“全面推广/成熟模式”。当推理缺口已明确而下一步需要资料时停止自我论证。
- **镜像检查**：审计重建成品实际主张；即使所有下层事实都真，上层判断是否仍缺条件？只替换形容词、填满表或重复自评，不算完成论证编辑。遗漏只有影响当前目标/必要判断时才是缺陷，可选新价值另列建议。

背景：[本地论证方法摘要](method-sources/sources/toulmin.txt)。方法资料不是本项目事实依据，也不认证证据充分。
