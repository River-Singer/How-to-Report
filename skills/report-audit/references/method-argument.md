# 让候选价值成为有依据的判断

在已有事实之上建立解释、用途、贡献或推荐时使用；也用于修复功能、投入直接跃迁成效果或承诺的断点。本卡承担主流程B中的论证，不另定义生产步骤。

先明确准备让听众理解什么，以及它对本次任务有什么用，再接上资料到判断之间的桥梁。已有能力怎样作用于具体工作？观察到的变化支持哪种解释？汇报者实际识别、选择或推动了哪一步，合作者承担什么？对这些关系找支持、反证、替代解释和关键条件；不要求把同一组框填满。

价值停在资料支持的层次：能定位原记录，可以解释怎样帮助核对；缺工时数据不妨碍用途说明，也不支持已节省工时。需要推荐时，比较选项对同一目标的差别，再核实际采用的理由。某项有业务核对安排，可以据此推荐，不能接着补“成本最低、机会仅此一次、其他随时可做”。推荐合理不替这些新断言提供证据；更多理由有新增解释或区分才保留，重要反证仍须讲。关键未知会改排序时，指出具体核实问题，不硬排也不把所有方向平铺成同等值得试。

个人贡献沿“当前发言人—实际行动—对过程或结果的作用”核对。画出或修改协作图，支持这项表达工作，不自动证明设计并管理了图中机制。已记录的判断与协作可以正面表达，无需先有量化收益；代表团队不拥有全部成果，模型新建议不变某人的历史成绩。希望得到认可决定内容重点，不证明听众已经或必会认可。

对重要推断问：下层事实都成立，上层判断是否仍可能缺条件？找到缺口后，补支持、收窄主张或形成条件建议。必要条件与充分条件分别核查，关系类比不能替代项目证据；资料不足不推出项目未开展。具体标准共用[含义保真](semantic-structuring.md#含义保真的共同标准)，新增区别由[解释探索](insight-discovery.md)处理。

交回可用的判断、依据和必要条件，或最能改变选择的待核事项。下一步需要事实就停止自我论证；不把每项候选和检验搬进正文。遗漏的重要性取决于本次任务，不能用未选的每一种角度否定已有合理材料。

背景：[论证方法摘要](method-sources/sources/toulmin.txt)、[受众价值与贡献研究札记](method-sources/sources/audience-value-contribution.txt)。它们提供方法启发，不是项目证据或Skill效果认证。
