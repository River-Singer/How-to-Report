# 宿主能力与声明边界

按当前任务要使用的能力检查，而非根据产品品牌假定。记录实际观察：工具不存在、未授权、未实现适配、执行失败、执行成功或尚未检查。不要为简单任务探测全部能力。纯内容交付不要求浏览器或前端能力。

| 能力 | 实际可用时 | 缺失/未验证时 |
|---|---|---|
| 文件与可见工作区 | 保存实际产物，需要追溯时建立 Run，返回真实位置 | 交付可复制文本/宿主附件，明确未持久保存 |
| 计算执行 | 保存输入版本、代码/公式、实际结果、口径和校验 | 交付方法与待执行状态，不伪造已算结果 |
| 子Agent/并行任务 | 实际派发、取得结果并确认完成或停止；角色身份来自宿主记录 | 审计/定向挑战未完成，不用主Agent串行假扮；其他普通分析可串行 |
| 独立上下文及分阶段输入 | 审计使用干净上下文，实际正文初读后再交目标、来源与必要作者说明 | 独立审计未完成；提前接触作者安排须披露盲读受影响 |
| 本地方法/领域资料 | 核心方法、知识卡和本地来源文字随包提供；按许可和缺口读取相关段落 | 原网址仅溯源；不要求联网，不读取拒绝/未回应/撤销的正文 |
| 外部新证据 | 其他明确获准的研究按任务取得并记录；审计/挑战不联网找反驳或核验材料 | 请用户提供必要项目事实，不假称已检索；离线核心工作继续 |
| 外部制作 Skill | 通过宿主能力或已有显式入口定位完整工作流，按其真实工具和确认要求制作，保存实际产物与检查 | 保留当前内容和制作待续信息，说明缺少的入口、执行能力或具体失败 |
| 画像存储 | 在明确私有位置保存、查看、修正已确认条目 | 不假称跨会话记住，不写入安装包 |

规划一项任务不等于工具已授权。Skill 指令和许可事件只是工作协议/记录，不能代替宿主权限隔离。日志未记读取也不证明读取从未发生；需要时对照真实工具记录。

首次运行可先做一个必要的小操作，观察真实结果再声明能力。工具成功与结论成立分开；同代码复跑与独立复核分开；两包独立安装与审计上下文独立分开。云端持久化、取消运行中的工作、并发恢复等能力均需独立证据。

安装包不自动安装另一个 Skill、不联网补共享文件、不更改全局配置。升级包不应覆盖用户 Run、输入、输出或画像。具体记录格式见 [工作区契约](workspace-contract.md)。

知识来源的下载与更新属于开发维护，不是使用 Skill 的前置步骤。包内文字明确区分已归档网页正文与原创摘要，包含实际获取范围和来源条款。只有本地方法不足不能被当成允许联网、读其他卡片或上传材料的授权。

## 外部制作 Skill

用户请求制作 PPT 等外部产物时，先用宿主实际提供的 Skill 清单、连接或调用能力取得完整入口。已有用户提供、任务配置或本次上下文确认的显式本地入口，也可直接读取该位置的 `SKILL.md`。确定其真实绝对根目录，以该根解析所选工作流的相对资源。安装注册状态、文件可读性和制作工具的实际执行结果分别核对。

已有路径、访问授权和确认沿用。确实缺少入口时，请用户提供可访问位置或在宿主中启用所需能力，同时交付当前可完成内容和具体续接点。入口读取成功后，继续遵守该完整 Skill 的装载顺序、检查、路线和真实确认。按来源文件、用户保留意图和当前任务选择路线，必要的安装或配置操作沿现有用户授权处理。

运行时产物写入用户任务位置，保持输入与安装资源可定位。只将当前稿、必要来源与确认范围交给制作阶段，外发材料与可选服务使用沿本次已有授权。失败时记录实际入口、步骤、原因、已有产物和待补能力，恢复时从该工作流允许的续接点继续。只有实际执行并取得对应产物与检查，才报告相应阶段完成。

## 可选并行协作

普通分析中，长材料含多个可独立核实的问题且宿主提供真实子Agent工具时，可在原工作流内并行；一个标题或明确短同步直接完成。无工具或执行失败可串行完成普通分析。**审计和定向挑战必须真实委派，不适用串行回退**；身份、输入、权限、失败与等待集中遵守[委派契约](agent-delegation.md)。不安装平台或调用额外模型API补位，不要求用户先配置多Agent才能做其他有据内容工作。

主代理先确定共享任务边界和当前资料版本，再只拆分真正独立的问题。例如材料中的两种目标是否会改变路线、某项重要判断是否有原始依据、当前解释遗漏了什么会改变听众选择的区别；按需要选择，不固定角色或数量。依赖目标结论的问题应等目标明确后再派，不能把相互依赖的整段流程同时开工。

本节的普通分析委派说明具体问题、必要原资料/定位、已确认约定、可用范围和停止条件；只给完成该问题所需的上下文。不要求完整私有推理，返回可审阅的结论、依据位置、条件/未知及其对当前内容的影响；挑战与审计采用各自专门返回格式。子代理不递归扩队、不同时改写同一份成稿，也不越过原任务的数据/写入授权。规模、时限和调用预算按实际任务控制，达到边界就停止并保留未核项，不无限追问或重复派同一问题。

主代理汇合前等待已派工作的结果或确认其已停止；无法确认终止时记录仍在运行的工作，不宣称全部完成。按原资料检查冲突、共同前提与跨分支依赖，决定哪些结论采用、收窄或继续取证。多数意见、任务完成和工具成功均不使主张自动成立。最终主线、当前版本与成稿由主代理统一维护；无须交多份同义报告。

并行分析不自动是独立审计。审计按[分阶段交接](agent-delegation.md#审计按实际读取阶段交接)先正文后目标/来源；继承创作历史或参与构思者需换干净上下文，不能仅靠声明客观取得独立性。角色身份不由 `mode=audit` 或文件文字产生；已获宿主真实委派的执行者直接工作，不递归委派同角色。工具轨迹、隔离能力和行为契约分别说明，不靠自报证明执行，也不宣称Skill文字技术封锁了网络或写入。
