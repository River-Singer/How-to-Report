# 概念与状态澄清

- **触发**：同一个“完成/进度/上线/价值”可能指不同对象、期间、分母或状态，差异会影响判断。词义已清楚或只是排版修改时跳过。
- **动作**：从材料列出本次问题涉及的对象、观察时点、比较参照、状态及计量口径。用两个边界例检验差异；保留资料原词和解释之间的对应。只定义本次需要的概念，不建设通用大本体。
- **可观察结果**：一段或小表写明原来混淆了什么、依据在哪、现在分别支持什么。例如“某范围开发完成80%”有明确分母时可以成立，却不自动支持“项目验收80%”；未验收也不反证前者虚报。假设例必须标成假设。
- **回落与停止**：把区别落实到标题、标签、分母、证据请求或结论强度；概念已足以指导本次取舍时停止。无法定义时请求原口径，不代作者补定义。
- **需挑战的地方**：实际表达对应哪个对象/状态，是否与资料一致？名称不同未必不同，名称相同未必同义；定义齐全不证明测量真实。
