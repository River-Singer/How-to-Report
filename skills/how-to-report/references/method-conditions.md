# 条件与相互制约

- **触发**：两个局部判断难以合并、优化一处损害另一处、同一做法在不同阶段产生不同结果，或所谓冲突类型尚不清楚。
- **动作**：先区分概念差异、事实记录冲突、目标权衡与机制交互。回看共同来源、时点和范围；对可变条件提出具体替代情况，比较受益者、代价、依赖和可执行权限。事实冲突先核证，不能靠折中数值解决。
- **可观察结果**：用简短关系说明标出“在什么条件下，哪项变化会影响什么判断/行动”；保留依赖，不把相关当重复。若存在第三种安排，写出成立条件与验证需求，不能为了折中发明方案。
- **回落与停止**：将条件写进实际建议、风险或备选。区分已足够、剩余缺口是事实，或继续仅换说法时停止；不强制正反各半、矛盾必有解决或每次寻找“主要矛盾”。
- **镜像检查**：单项均成立是否足以支持综合结论？是否用阶段不同抹去真实矛盾？是否把潜在交互当实测机制？若变化没有相关的判断后果，不算有效发散。

背景：[本地条件分析说明](method-sources/sources/conditions-background.txt)。哲学背景与经验事实、LLM实验是不同证据类型；本方法不要求采用特定哲学立场。
