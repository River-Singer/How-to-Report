# 叙事与内容的可观察检查

文件名为旧引用保留；当前职责只覆盖叙事、内容分组与文字成稿，不包含视觉制作或验收。按实际问题使用下面的动作，无需每次列清单、写全部编号或创建Graph。发现问题先修内容，再保留必要的决定和依据摘要。

## 路线是否完成本次沟通

- **从结果找内容，也从内容反查结果。** 新建或实质重构时，从确认的结果找必答问题及支持内容，再看每段服务什么。正式必答、必要背景和已确认个人诉求各有职责。缺必答或夹入无关内容时调整主线；缺证据则补证或收窄判断。不要仅将新目标写在开头而沿用旧目录。
- **只比较有实质差别的路线。** 存在真实分歧时，比较起点、听众疑问、结束状态、证据负担和取舍。不同方法名或标题不算区别。明确目标的短任务无需列备选路线；必要取舍用简短说明即可。
- **串读判断并从结尾反查。** 看前一段解决了什么、下一段为何必要，再逐项回查最终判断或请求的支持。缺背景、缺证据或离题，回相应位置修复。标题串读只是辅助，过渡顺畅不证明论证成立；提问、导航和演示标题可以承担不同职责。

## 内容是否完成理解任务

- **分组有共同问题。** 一组内容要让听众理解或判断什么？哪些需要放在一起比较，哪些需要先解释？先按关系组织，适合分页的任务再建议页序；按文件数量、主题词或固定三点分组并不足够。局部并列不决定全局路线，按需用[语义组织](semantic-structuring.md)核对分组、关系与上层概括。
- **关键细节有责任。** 对主要判断保留所需事实、解释、条件和行动。比较正文、标题与讲稿的确定程度，避免阶段记录变成成熟成果或未来目标变成业绩。独立阅读版另查上下文是否自足。正文方法见[观众成稿编辑](audience-copy.md)。
- **重要信息没有在精简时消失。** 删除、合并或转备查时，反查原要求和决定性条件。制作提醒回工作记录，来源细节按需提供，讲稿仍能直接讲述。短修改只需核对受影响内容，复杂重构才记录去向。

比较或综合多组资料时，核对对象、时间、单位、基线和计量定义。两项结果各自为真不保证可以相加或共同支持结论；两时点变化不自动证明持续趋势；重叠清单不能作为互斥整体。重要数字按[数值方法](numeric-evidence.md)实际复核。

## 成稿与修订

先不看制作理由读正式正文，复述其主要判断、关系、条件和请求，再对照原要求与资料。发现说话身份错位、上层概括过强、顺序暗示因果或重要内容遗漏，修复最早出错的地方。已经见过计划就披露，不能把同一作者自查称作盲审；模型复述不是听众实验。

修改按真实影响复核。只改措辞不重开目标或增加成绩；数据变化同步影响相关数字、判断和结尾；目标或听众改变时重新看路线与取舍。保留原件和旧检查的适用版本，不继承旧版通过。

当正文能完成已确认的沟通任务、事实与必要条件有支持、重要未知明确时交付。是否初始化Run、有没有检查表或采用某种框架都不是内容通过标准。使用Run时沿用现有Check状态，只记录实际执行的检查；没有做的不能标通过。方法存在不代表模型已经稳定做到。
