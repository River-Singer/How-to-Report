# 寻找现有表示遗漏的重要区别

完整判断或决策类汇报在主流程收敛前主动检查有没有遗漏重要区别，不等模型已经发现盲区才开始。材料只有罗列、关键判断缺桥梁或新证据冲击主线时，再深化相应方向。明确短同步或局部改字无需强行发散；本方法只交回候选与取舍依据，审计用它检查重要遗漏，不默认重做整份报告。

## 找出当前表示的盲区

先辨认当前问题、对象/分析单位、时间范围、系统边界、已有判断与事实锚点，无需另写一份说明。试问：这些现有属性相同，听众是否仍可能需要不同判断？从材料里的异常、冲突、被总量掩盖的差异、实现条件或受益方约束中找线索。明确该区别为什么值得本次听众关心，而非只因新颖。

抽象时保留会改变判断的范围、数量、时间、角色和约束，并能返回原资料。若抽象后只剩“体系、价值、效率”等词，恢复谁在何种条件下对什么对象做了什么、相对什么参照发生变化的具体关系；若没有实质盲区，停止无目的升维。

## 选择表示变换，产生可挑战的候选

按当前盲区选操作，不要求跑完下表：

| 盲区 | 变换与预期区别 |
|---|---|
| 只有对象属性或功能清单 | 转看过程、依赖、约束与相互作用，寻找现象如何发生 |
| 总量或平均掩盖差异 | 调整粒度、时间尺度或分析单位；拆开混合概念，检查比较口径 |
| 单一解释过早占主线 | 寻找竞争解释、负例与边界情况，提出能区分它们的观察 |
| 只有症状或局部改进 | 扩展/缩小系统边界，追踪前后依赖和实现条件，检查影响是否转移 |
| 熟悉框架没有新增解释 | 用关系类比或已授权专业知识提出新机制；列明映射及会破坏迁移的差异 |
| 局部分析都成立却难以联合 | 回到相关原证据，联合检查定义、时点、范围及跨路径交互 |

专业领域不是固定坐标轴，表示变换也不必增加变量。自然语言没有通用内积；语义距离、embedding、Gram–Schmidt式类比、逻辑不等价、统计独立、机制不同与解释有用不能互相认证。

以独立问题或完整判断保留候选，逐渐明确其材料线索、相对旧表示的新增贡献、尚属推测的部分、可区分的观察，以及不同答案会改变的判断或行动。一个操作性判据是：构造两个符合已知约束的假设情境，它们在旧表示上相同、在新方向上不同，而合理判断或行动应不同；说清具体差异。它只帮助检验新增区分能力，不能把假设情境当现实事实或数学正交证明。探索可以先于证明；候选无充分证据时继续标明假设，不把潜在变量写成已观测事实，也不因暂未证实就删光新方向。

专业卡需要时先读 [知识目录元信息](../knowledge/index.md)，说明资源、用途和读取范围；仅在同范围有效许可内读正文。核心探索不能通过重命名资源绕过领域知识许可。

## 辨别候选之间的关系

- **去掉标题比较完整判断**：检查同义、包含、同一机制链的不同环节、竞争或互补；不同领域标签不保证不同内容。同一问题的反命题通常是竞争答案，不因否定句就增加一个维度；它仍可能是必须保留的反证或备选解释。
- **区分测试**：在已知约束内，什么观察会让两候选获得不同支持或导出不同建议？可构造一者成立而另一者不成立的情境，但思维反例不能证明现实机制存在。
- **删除测试**：暂去掉一个候选，是否损失重要解释、必答问题、决策差异或限制？没有损失时合并或删除；重要反证不能为简洁牺牲。
- **交互测试**：候选是否共享条件、相互制约或组合后产生单独分析看不到的效果？联合看原始资料及适用边界，不能只拼接不同工作者的摘要。

相关不等于同义，例如交付周期与投入工时可能共同变化，但一个涉及等待/流转，一个涉及实际劳动，若会改变不同决策就应保留；不得仅因相关而合并。不同机制可以相关或处于同一因果链，不为追求“正交”强行切开；保留必要的依赖和交互。对尚不能区分的候选保留竞争关系与最有辨别力的证据需求；不按修辞吸引力、观点数量或模型自评分选“真相”。

## 收拢本次探索，交回判断

保留有新增区分的候选、证据线索、依赖或竞争关系，以及最能改变判断的未知；同义候选合并，无关新颖暂放。采用的区别要带回主张比较，实际改变解释、选择理由、主次或条件；若只能留作补证问题，要说明什么答案会改变当前选择，不以末页多一条“建议验证”算完成价值发现。必要时保存简短取舍摘要，不要求每候选一个文件或Graph，也不输出私有推理。多路径综合仍需回看原证据，不能用多人一致代替依据。

先针对当前盲区探索少量方向，再围绕新发现补缺，不设初始或最终固定数量。重要问题尚未覆盖、继续探索仍能得到有价值区别时继续；新方向只是改名、离题、关键差别只能靠资料核实，或达到时间/交互预算时停止。预算停止要保留未决和未探索范围，不声称穷尽。

输出的是可供判断检验的候选，不是已证明的新结论。论证、叙事和交付由调用者的主工作流接续；不在这里另走一遍完整生产流程。新方向通常改变判断或条件，只有实质影响已采用目标或其可达性才按[目标发现](goal-discovery.md)提出取舍，不能静默换题。

概念、前提、条件与论证困难见[思维方法](reasoning-methods.md)，具体编辑例见[连续教学](content-decisions.md)。改前改后真正改变了什么判断或所需证据，才是探索的结果；新增形容词不算。
