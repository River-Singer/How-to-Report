# 离线方法来源

本目录为核心通用方法的背景，不含可选领域卡。31份均为原创短摘要，记录实际阅读范围；不是全文下载，也不证明本产品的模型表现。只读当前疑点所需的条目，无需把目录全部装入上下文。网址仅溯源，离线即可使用；完整元信息和哈希见[清单](sources/manifest.json)。

## 从目标到内容：按疑点选择

- 选出了关键判断，正文却仍按旧目录展开，或更正后留下依赖错误：[判断如何进入正文](sources/judgment-led-editing.txt)。四项选读区分研究发现、方法迁移和适用限制；只在相关疑点出现时读。

- 零散记录怎样形成有内容的概括：[阅读与跨段摘要](sources/reading-synthesis.txt)。区分归并、概括与新增推断，保留理解所需前提。
- 改了措辞仍未解决读者的理解问题：[示范、反馈与支持撤除](sources/revision-coaching.txt)。用具体改稿支持当前难点，不把更多方法当作更好效果。
- 顺畅叙事是否掩盖推断缺口，听众是否要同时记住太多未解释关系：[论证与信息整合](sources/reader-argument-attention.txt)。不从容量研究推出固定点数。

- 对方是否已经知道这些背景：[共同理解](sources/grounding.txt)。AI与委托者的共同背景不能直接代替听众背景。
- 要不要继续问用户：[澄清的帮助与成本](sources/clarification-value.txt)。目标歧义、事实缺口、知识不足分别处理。
- 信息还不全能否给出建议：[当前知识下的决策](sources/decision-under-uncertainty.txt)。先看哪些未知会改变选择。
- 怎样分析试点的借鉴范围：[情境、机制与迁移](sources/mechanism-and-transfer.txt)。保留条件判断，不编普适门槛或收益。
- 讲述顺序是否改坏了关系：[文本关系](sources/text-relations.txt)。叙事作用与业务事实分别核对。
- 需要取得专家修改背后的经验：[具体判断访谈](sources/expert-judgment-capture.txt)。仅在用户同意后做经验采集，不能只凭成稿猜历史。

落实到实际取舍可读[合成教学对照](../content-decisions.md)。下面保留既有来源；视觉技术条目是历史参考，不恢复 HTML 生成责任，也不是当前内容任务的必读项。

- 怎样把事实与本场听众的任务、贡献和取舍连接：[听众价值与贡献](sources/audience-value-contribution.txt)。实验、摘要、回顾研究与机构实践的阅读范围分别保留；不是说服保证。
