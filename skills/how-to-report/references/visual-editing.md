# 从参考方向到整稿视觉编辑

> avoid unnecessary secondary labels and descriptions. Let the layout do the explanation

先按[观众成稿编辑](audience-copy.md)完成可以直接给听众读的文字：已确认目标 → 页面任务 → 主要判断/行动 → 必要事实与条件。内部制作目的、字段名和核验过程不自动成为正文或讲稿。先只读成稿核对理解与保真，再进入布局；分析正确不代表成稿已经清楚。

标题、卡片小标题、正文、图注各有新增职责才保留，不要求每块都有全套说明。对齐表达对照，分支表达共同起点，层级表达明确的包含/上下位关系，泳道表达职责；位置和连线不能暗示未提供的先后或因果。图已讲清的关系无需在主画面重复完整节点/边清单，文本替代和完整引用留在可达详情。关键预测条件、未批准和未验收状态仍随主张可见。

按当前任务及用户已明确的参考提炼配色、字体层级、留白、边界、控件和阅读节奏。记录简短方向及其用途，沿用已确认偏好，不反复询问。默认一个醒目的主标题；自然换行可以，禁止为单行无限缩字。问题、结论与限定属于语义计划，不必机械全部叠在页眉；会改变判断的条件在相关内容处可见。

复杂证据页与简洁判断页分别用真实标题、最长标签、来源和必要限制粗排，再检查是否像同一份稿。对于确有组织分歧的复杂页，可比较证据主导、机制主导或对比主导的两种方案，说明理解路径和空间分配的差异。只换颜色不算另一方案；简单页无需两版。

能力分流先看表达职责：确需真实截图/视频则使用可核对的原素材，确需依赖/泳道/表格则保留关系，不因工具Schema只会卡片就改写内容。使用当前支持组件；未支持的表达另交明确语义方案或请求素材，不捏造播放入口，不向受控渲染器注入任意HTML/SVG。局部标注说明其对象，不遮住决定性状态、单位或限制。媒体版本、范围和来源须可追溯。

整份成品形成真实截图缩略图/联系表（有工具时），核对语义颜色、单位/状态标识、重要证据的空间、重复布局与节奏。重复可以帮助同口径比较，变化应服务内容，不设每几页换一种模板的配额。没有截图能力时明确只做源文件/结构检查，不能称已看整稿。

代表页同时查拥挤与稀疏：关键图被长说明挤成细条、节点不可读，以及大片空卡包住细小关键内容都要处理。先定位需要读者判断的对象，再分配空间，不以每卡等高、每页等量或SVG存在作为通过。分支/反馈页先从截图反读实际边，再对照输入；穿过第三节点的线可能制造并不存在的关系，不能靠下方说明纠正。

粗排、逐支持状态渲染与反读继续按[叙事页面检查](narrative-page-behavior.md) L01/L02/A01/A02执行；容量不足先重分空间、删重复装饰、换表达、分层或拆页。几何通过不证明可读，缩略图一致不证明意义正确。反馈先定位术语、主次、关系、容量或目标问题：只改间距就保持事实与路线；“像秀技术”则核对主线与受众问题，不只替换名词。

离线依据与范围见[视觉方法来源](method-sources/index.md)。这些是操作指导，成品质量仍需实际页面与用户案例证据。

## 已确认的默认视觉方向

本版默认采用用户已确认的克制 Apple-like 方向：近白纸感与浅蓝柔光、轻薄边缘和柔影、大圆角、无衬线黑灰正文及少量蓝色强调；磨砂只用于适合的界面层，正文可以轻盈但必须保持实际观看尺寸下的清晰对比。内容职责决定布局、空间和证据面积，不为风格把每页填成同样卡片。用户本次的明确风格要求优先。

巨型淡字或数字后景、轻微倾斜和错位仅在封面、转场等能帮助定位或节奏的位置按需使用。普通页仍默认一个醒目主标题，不重复叠加背景大标题，不以截图当装饰。正文、数值、坐标、关系和证据面板保持可读、可比；不能扭曲数据图形来制造动感。

实际页面检查除容量外，还应暂时移除装饰比较阅读路径：背景是否让潜在价值像已实现收益、暗示未经支持的增长，是否遮挡图表/限定，是否使正文和状态标记对比变弱。出现这些影响就减淡、移位或撤去装饰，保留关键内容。没有实际渲染只能记录设计意图，不能声称磨砂效果或可读性已通过。
