# MKT-01 用户问题、采用与指标链

版本：0.1.1。核对：2026-10-26。可选产品营销轻量卡，仅在许可覆盖本卡时读取。

## 何时用、需要什么

用于“用户需要、用户接受、推广成功、产品有价值”等主张。需要目标人群、使用情境、研究/行为材料、事件定义和观察窗口。没有市场决策任务时不扩展成市场规模、定价或完整营销战略。

## 执行动作

1. 从用户要完成的事及困难描述需求，区分实际研究证据与团队假设。已实现功能是一个解决方案，不能据此倒推用户必然需要它。
2. 根据当前产品的真实过程辨认接触、尝试、任务完成、持续使用或交易；这些不必组成固定漏斗，也不能用前一层数字替代后一层。一次性服务不因缺少“留存”而自动失败。
3. 逐个关键指标核对对象、事件、分母、渠道和时间；确认相同对象能否跨步骤连接。若比较数字渠道采用，需要知道同范围其他渠道的情况，不能仅凭访问量上升下结论。
4. 将行为结果与用户问题联合查看：增长来自需求满足、渠道迁移、推广曝光还是统计范围变化？提出可区分的证据需求，不从满意评价自动推得购买或实际收益。

## 交付与独立审计

输出有证据的用户问题、当前可观察行为、价值假设及尚缺验证。若材料揭示新的受众问题，可提出目标候选，由本次目标选择决定是否进入 Blueprint。

审计检查用户假设被写成研究事实、渠道/群体选择性展示、把流量当成功，以及用政府服务的具体定义替代当前产品规则。关键事件或分母不明时，停止采用率/转化率结论，保留可核对的原始观察。
