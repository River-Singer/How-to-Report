# SWE-02 技术能力与可靠性证据

版本：0.1.1。核对：2026-10-26。可选软件工程卡，仅在许可覆盖本卡时读取。

## 何时用、需要什么

用于“已支持、可稳定运行、易维护、可推广”等技术判断。需要相关版本、场景、环境、测试/演示记录、运行观测和已知限制。没有服务运行需求时，不强制引入 SLO。

## 执行动作

1. 将能力主张限定到具体行为与使用条件。分别标明原型演示、离线检查、集成结果和真实运行观测；测试通过只支持实际覆盖的条件，不自动保证长期可靠。
2. 若需讨论服务水平，区分观测指标 SLI、目标 SLO 与带后果的服务约定 SLA。记录测量窗口、采集位置、纳入对象与阈值来源，不凭当前表现替用户决定承诺。
3. 比较测量与用户实际体验：服务端代理指标是否遗漏客户端问题，平均值是否隐藏尾部或突发。选择能改变判断的分布/场景，不要求每次收集所有指标。
4. 对可维护性说明可观察依据，如变更影响范围、复现/回归条件和维护记录。把“架构看起来整洁”保留为设计理由，不能代替实际维护效果。记录尚未演练的故障、恢复或环境条件。

## 交付与独立审计

输出“支持的能力—验证条件—证据位置—未覆盖范围”，并据此形成技术判断和必要的验证任务。审计核对实际版本、环境差异、仅测正常路径、指标与用户问题错位，以及测试数量被当可靠性证明。

已有证据能支持限定结论时即可交付；未测生产或恢复场景保持未验证，不执行未经授权的生产压力/故障实验。
