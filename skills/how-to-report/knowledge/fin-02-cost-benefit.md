# FIN-02 成本收益与敏感性

版本：0.1.1。核对：2026-10-26。可选财务卡，仅在许可覆盖本卡时读取。

## 何时用、需要什么

用于准备或审查成本收益、TCO、ROI 等模型。需要所比较选项、期间、币种、实际采用的指标定义、成本/收益清单、估计来源与关键假设。无必要数据时先给可执行需求，不生成看似精确的比率。

## 执行动作

1. 先锁定决策问题与比较边界，再列增量投入和效果。TCO 的期间应说明建设、迁移、运行、维护及退出哪些部分已包含；缺项写明，不能默认不存在。
2. 对每项列数量、单价/估值依据、发生时间、归属对象及实际/预测状态。检查共享成本分摊是否有约定，避免跨选项或跨时期重复计入。
3. 将本次采用的公式、期限与处理约定写明后，使用真实工具计算并保留输入版本。ROI、收益成本比、回收期不是同一指标；本卡不预置万能公式、贴现率或税率。
4. 找最可能改变判断的假设，按有依据的范围改变它，观察排序或结论是否改变；区分情景范围与统计置信区间。没有可支持的范围时给出待核对的临界条件，不编概率。

## 交付与独立审计

交付可复算的模型/凭证、关键假设、结果适用范围，以及无法货币化但会影响选择的事项。审计从输入复核公式、漏项、期间、币种、正负号与重复归属；工具执行成功不等于模型合理。

当基础定义或成本边界不清时，停止报告单一 ROI；可先交付比较表和证据请求。涉及正式会计、估值或税务结论，使用适用专业规则另行核验。

## 来源与边界

[Green Book 2026](sources/green-book-2026.txt)：定向读第6章的 time horizon、成本类型及 sensitivity analysis / switching values。这里只借鉴全期考虑和假设检验原则，模型检查流程为本项目综合；没有将政府社会收益指标冒充企业 ROI，也没有复制其固定年限或贴现参数。

离线使用：上面的来源均指向随包文字，原网址仅用于溯源。只在本卡已获许可的相关范围定位所需段落；不要默认通读全部来源或联网补齐。来源是方法依据，不是当前项目事实。
