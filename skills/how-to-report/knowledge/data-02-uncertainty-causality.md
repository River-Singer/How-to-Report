# DATA-02 不确定性、对照与因果主张

版本：0.1.1。核对：2026-10-26。可选统计数据卡，仅在许可覆盖本卡时读取。

## 何时用、需要什么

用于“提升、导致、预测、显著、代表总体”等判断。需要实际研究问题、数据采集方式、比较或干预设计、样本及方法记录。只有个案描述时不强迫做显著性检验。

## 执行动作

1. 先区分描述已观测对象、推广到总体、预测未来与判断原因；它们需要不同证据。用户想证明某效果，不会使它先成立。
2. 对变化提出与材料相关的替代解释，例如样本构成、同时发生的干预或测量变化；寻找能让候选得到不同支持的观察。不能把“相关”改写成“导致”。
3. 说明如果没有该干预会发生什么的比较依据，以及分配/选择方式、时间顺序、可比性和可能混杂。对照或随机化是设计信息，不是读到标签即可通过的认证；更复杂因果方法需要另行核验假设和实际执行。
4. 估计结果保留样本、方法和不确定性。置信区间、情景区间与个体预测区间不得混称；经典置信水平描述重复构造区间的方法覆盖性质，不能直接解释为本次主张为真的概率。

## 交付与独立审计

输出目前支持的结论层级、尚未区分的候选、最小新增证据或验证方案。实际计算时先检查适用条件，再保存可复核凭证；未计算不能凭模型直觉补出区间或显著性。

审计从研究设计和原资料检查选择偏差、遗漏竞争解释、事后改口径及因果越界。不显著不自动证明没有效应，资料不足也不等于主张被证伪。没有识别依据时停在描述/关联或待检验假设。
