# COM-02 传播目标、观察层次与效果贡献

版本：0.3.0。核对：2026-11-12。可选沟通公关卡；仅在有效许可覆盖本卡及相关来源时读取，不扩大既有授权。

## 判断问题与输入

公关/传播做了什么、改变了什么，曝光能否支持理解、信任或业务效果。

必要输入：本次传播目标、受众及其关系、活动/渠道记录、指标定义、对象/期间/基线、反馈或行为记录以及同期共同干预。

## 实际操作

1. 从实际受众要理解/行动的事界定传播能改变的部分，区分仍依赖产品、服务或交付的条件。
2. 把现有指标分别对应活动、接触、理解/态度、行为与组织结果；不是强制漏斗，也不把前层替代后层。
3. 核每项观测对象、期间、分母、反馈方式及可比基线；同一曝光可能重复，点赞不能自动量出信任。
4. 对照同期促销、产品、渠道、事件和受众变化，区分已观察变化、可信贡献与未验证因果；需要时在有效许可内用DATA-02，不能因无随机实验抹掉真实阶段价值。

## 产物、限制与停止

交回最高有证据支持的传播结果、作用机制和必要限定，形成复盘/续投内容。清晰稿件、传播完成与受众效果不同，也不采用广告价值等价数替全部传播价值。

只有曝光时保留触达事实，要判断信任还需最贴近目标的反馈；必要缺口明确求助，不把未测改写成没有效果。不启动真实发布或全渠道监测。

汇报人负责完成这些分析并组织为可理解的内容；挑战者用同一知识按真实职责检验最强的目标相关阻断，实质输出仅问句，不给答案或修法；独立审计核实际内容、来源与执行，不按方法名称判通过。角色与派发规则见[委派契约](../references/agent-delegation.md)。

## 短应用与误用

合成例：文章被阅读一万次、问卷反馈显示部分读者理解流程，两项分别说明触达与该样本理解；没有行为数据不称业务转化已提升。误用：将播放量直接换成信任、收入或传播因果。 以上均为合成教学例，不是用户项目事实或固定问题模板。
