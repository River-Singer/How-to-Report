# How to Report

帮助用户找到值得讲、能够成立、适合本次沟通的内容。支持 `create`、`revise`、`analyze-first`；只要求检查现有产物时，应使用实际可用的独立审计能力。两个 Skill 是入口，多种 Graph 是内部工作视图。

## 从当前缺口进入

- `create`：从已给材料和情境发现本次及潜在目标，区分明确要求、意图假设和新建议。方向未定时，用简洁结构图呈现候选主线、关系、重点和证据缺口，让用户的取舍改变方案。
- `revise`：确认目标产物和修改范围，保留未授权改动的内容；识别受影响的主张、引用和检查，输出范围内修订。
- `analyze-first`：先交付候选解释、实际分析结果和证据请求，再决定是否需要讲稿或页面。不要为完整流程而强制生成 Deck。

简单任务可以直接形成短内容；复杂任务可往返探索、取证和收敛。不要要求固定阶段数、观点数、业务维度或每种图都生成文件。

上述 references 是按需核心方法，knowledge 中的卡片是可选领域知识。目录元信息用于选择资源；不能在许可前批量读取卡片正文。按用户已确认的资源、用途、数据流向与 Run 范围读取；拒绝、未回应或撤销时停止相关读取，继续使用已授权材料。既有同范围许可不重复申请。

本包按离线使用准备：核心方法、知识卡及其本地来源文字均随包提供。原网址只作溯源，不是必须执行的联网步骤；需要查依据时在已授权范围内定位相关本地段落。来源注明正文或摘要及其边界，不能将摘要当全文。缺少项目事实时记录缺口或请求用户提供材料，不假称已经搜索、下载或核验。

## 保留关键区别

- 假设不是事实，任务完成不是结论通过；来源、观察、主张、证明义务、内容和页面保持必要的稳定引用。
- 用户采用某目标不使其事实前提成立；报告写完不证明听众理解或行动。新解释可促使重议目标，不能静默替换用户选择。
- 论证 `links`、版本依赖 `uses`、任务 `prerequisites` 各有含义。不要由一条支持箭头自动推导执行顺序、因果或可信度。
- 对重要比较、效果、因果和收益主张，说明缺什么证据、它影响哪个判断、拿不到时可怎样诚实表达。限制、反证和重要风险不能因压缩内容而消失。
- 图记录可检查的对象、关系、理由摘要和证据，不记录模型私有推理过程。
- 使用已确认画像时遵循本次明确要求；临时偏好和模型推测不自动成为长期条目。按用户要求查看、修正，并在私有位置实际保存。

## 交付与检查

需要持久保存本次工作时，按 [生成 Run 的建立与续接](references/report-run.md) 创建外置的新目录，或先检查已有 Run，再读取本次范围内的真实记录和用户新要求。初始化只登记明确提供的本地文件快照，不代表已经阅读、分析或完成汇报；续接时不重新初始化，也不把历史 `completed` 当作当前仍有效的证明。短任务只保留必要记录，不强制运行脚本或建立空图。基础 Blueprint 应表达中心问题、完整判断、材料支持、限制、模块关系和关键缺口；内容单元与页面不是一对一。

确需计算或渲染时使用当前真实工具，并保留输入版本、方法、实际输出及检查范围。重要数值给出本次必要的区域、单位、公式与舍入口径，区分复算、计划估计和现实测量；缺少定义或未执行不能写成计算通过。没有相关能力时交付可用部分并说明未验证项。本包提供有界的离线16:9 HTML工具，按 [内容到HTML](references/report-html.md) 生成并实际检查；它不自动判断页面语义或执行任务。

查看已有生成 Run 的登记状态时，使用 [Run 助手](scripts/report_run.py)；需要查询声明的版本影响时，使用 [Run 校验器](scripts/validate_run.py)：

```text
python <本Skill目录>/scripts/report_run.py inspect <本次Run目录>
python <本Skill目录>/scripts/validate_run.py <本次Run目录> --changed source-id@1
```

两者只读检查记录；已有 `version_state` 时，`report_run.py inspect` 同时展示生命周期检查及接纳状态。明确选版和记录接纳使用 [版本操作](references/version-lifecycle.md)，不能由结构通过代替。`inspect` 显示实际登记状态，`--changed` 查询适用性变化的旧精确版本所影响的显式依赖。它们不选择业务最新版本，不自动续作、修改或重算，也不证明洞察、证据充分性或页面正确。

成稿交给实际可用的 `report-audit` 或独立审查上下文，提供原始资料、用户要求、实际产物和核对当前声明所需的最小附件；明确本包省略、当前不可得和不在范围的材料。历史谱系按本次问题提供，不默认附上全部旧审计或 Blueprint。不要只交生成者自评。若无法独立审计，可交付工作稿及有限自查，明确独立性和未完成检查；未解决 P0 不能声明可发布。用户要求只审计时不自动改写原件。
