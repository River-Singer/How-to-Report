- audience画布不生成page/element footer或引用编号，指定备注完整移入资料；同输入review仍保留旧显示。实际正文条件和原始计划保持，映射不把detail-only limits称为displayed。

## 复核边界

新方法要求作者先把真实业务条件写到相应正文，再选择audience；渲染器不根据关键词猜重要性，不自动重写旧稿，不全局隐藏small文字。完整资料仍在HTML/计划/映射中，资料折叠不构成访问控制或脱敏。方法及MIT归属均可离线读取；新增公开证据全为合成输入，没有复制用户r2正在生成的结果或私有案例。

第一次工程结果保留在[iteration01](iteration01/README.md)，其receipt仍对应当时的实现。随后实际预览复核发现Gantt仍有日期台账、图例解释尾句和缺进度的孤立“未知”；在限定范围内调整投影后，重新运行最终全量测试与6页浏览器检查，并新增精确日期详情核对。没有把旧receipt改成新实现通过记录。

最终身份见[release-receipt.json](release-receipt.json)。工程检查仍不能代替实际成稿审查。
