浏览器实测使用 Windows 11 上的 Chromium **145.0.7632.6**。分别实际生成 1600×900 和 1600×1000 两种画布，每份 6 页，覆盖 1600×1000、1280×720、1024×768、390×844 四种窗口。

检查包含逐页真实边界、SVG 内部几何、值/单位/引用/限制对应、折线缺失断点和已知点、矩阵负数/零/缺失、完整标签、翻页/深链接、阅读模式和打印状态恢复，以及长正文/长标签超框反例。未发现非预期网络请求、控制台错误或脚本错误。最终浏览器第二轮使用的 9 份相关运行文件与最终安装包字节一致。

两份实际打印 PDF 均为 6 页，尺寸对应配置；默认高度由 Chromium 舍入为 675.12pt，名义值为 675pt。逐页文本检查覆盖标题、限制和元素标题；视检覆盖全部默认屏幕页、移动阅读与横向滚动截图、长标签反例，以及两种画布的 PDF 第 5–6 页。没有宣称覆盖所有浏览器、打印机或业务语义。

本轮发现并修复两项问题：

- 移动阅读模式中折线 SVG 与数值表宽度不同，导致点与期间错位。两者改为同一滚动区内共享 540px 最小宽度，并实际核对滚动后点/单元格中心，最大观察偏差小于 0.033 CSS px。
- 首次完整测试为 182 通过、1 失败、1 跳过：隔离测试夹具复制了源码目录中已有的编译缓存，误判为 CLI 新写入。夹具已按真实打包规则排除缓存，并保留执行前后无缓存断言；定向重测及第二次完整测试通过。首次失败和修复记录仍保留，未删除源码缓存或修改工具来掩盖问题。
