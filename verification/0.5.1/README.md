可打开 [演示组件](browser/advanced/index.html)、[进度视图](browser/schedule/index.html) 和 [折线数据对应](browser/line/index.html)。这些工程输入仍含解释性测试文案，只用来核对装配与交互，不能当作优秀观众稿模板。代表图见 [职责泳道](browser/advanced/page-03.png) 和 [日期漂移](browser/schedule/page-06.png)。SVG 字体测量提供实际大小，不自动认定适合现场观看；几何通过不等于语义或视觉设计通过。

## 本轮复核修复

新增较大的进度图字体曾使漂移图最高数值标签越出 `viewBox` 顶部约 1.51 单位。已保留字体大小并增加绘图区顶部余量；真实浏览器回归确认数值、日期及折线仍在界内，日期间距和数据未改写。扩展浏览器工具同时加入完整来源与真实打印检查；调试时纠正了“来源上下文必须都是独立 datum”及 Playwright 强制 screen 媒体影响 PDF 的测试假设，没有放宽实际引用、容量或打印要求。

完整运行的相对文件名与 SHA-256 保存在浏览器 receipt 的 `evidence_files` 中。复制到本目录保留这些字节；receipt 中执行时的绝对工作目录仅记录原始运行位置。最终包指纹见 [release-receipt.json](release-receipt.json)。旧版本证据和用户案例未改写。
