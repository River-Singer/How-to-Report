# Historical visual implementation — 0.5.3

These original source files, assets and tests were archived when 0.6.0 stopped producing HTML/SVG presentations. They are excluded from the current Skill packages and current test discovery. The exact source hashes are in [archive-manifest.json](archive-manifest.json).

This is an archival subset, not a standalone installation. Paths/imports in historical files deliberately retain their original meaning. To reproduce the complete old implementation, use a separate checkout of commit `071592ad59ea2bbe62ef9ea9e728d3dea4e38181`, then follow that commit's build and verification instructions. Do not mix current 0.6.0 shared helpers with archived renderers.

Original published evidence remains under `verification/0.5.3/` and earlier version folders. Those records describe the old implementation only; no old check is relabelled as a 0.6.0 content-quality result. The archived schedule and packaging tests preserve mixed visual/nonvisual history. Current tests retain numerical, chronological, package-portability and file-boundary checks separately.
