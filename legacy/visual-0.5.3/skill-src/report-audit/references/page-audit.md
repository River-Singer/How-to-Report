# 实际页面的视觉与语义审计

> avoid unnecessary secondary labels and descriptions. Let the layout do the explanation

本要求同时检查信息过载和表达不足。不能只统计字数、卡片或SVG；先从实际成品辨认主要判断、重要请求、关键条件及真实关系，再按[观众成稿编辑](audience-copy.md)核对分组、概括、角色与含义保真。说明少了但条件丢失仍是缺陷，来源折叠不等于已经脱敏。

先锁定本次被审的实际 HTML/页面版本和授权范围；要求与原材料的内容对照放在首轮页面反读后。只写自己的审计结果，不能修改被审HTML、计划、图或Run。外来HTML同样可以审查，不要求装有生成Skill或具备生成计划。

## 先反读，后看计划

按 [叙事与页面行为](narrative-page-behavior.md) 的A02保持本节顺序。随后按V01/V02/S01/M01/L01/L02/A01审查表达增量、数值与SVG语义、多视图共同意义、容量/状态和注意力；R01核对修改是否越界以及联动检查是否真实。记录具体依据、影响和最早出错层，不按图形数/美观总分判定。

若要声明独立视觉语义反读，先打开实际页面，逐页记录读者会得到的核心判断、比较关系、因果暗示、范围及行动要求；组合页面还要记录主辅面板、跨块关系和实际阅读顺序，不能只逐卡转抄；此时不读取生成侧 Blueprint、PagePlan、映射或自评。记录实际上下文继承和已暴露内容。如果浏览器展示源代码而非渲染页面，不能声称完成视觉反读。

随后再读取本次原要求、原材料和必要的计划/映射，核对支持程度、重要遗漏、过强表达与版本。映射只提供定位线索；程序对上ID不证明页面语义等价或原材料足够。未提供计划时直接从实际产物和原资料继续审查。

分别检查：主要请求是否被大数字或制作旁白盖过；标题/正文/结尾是否反复说同一句；图下是否重复完整节点/边清单；小字和页脚是否在向制作者下指令、复述“预计”等已有含义或用免责声明补救过强主张；共同起点的并行分支是否被排成串行；反馈边是否绕过无关节点并明确指回对象。先写实际读到的关系，再查输入边，不能用源码中有箭头证明成品表达正确。

## 实际浏览器检查

记录HTML指纹、浏览器/版本、窗口尺寸、页ID及真实观察。测试导航、键盘、直接页链接、缩放和打印媒体；逐页看关键元素是否被裁剪、重叠、遮挡或因缩放难读。可读取页面提供的几何检查接口，但应结合实际截图/页面，不能把页面自报当独立结论。自报成功不替代人工判断，失败需核对实际影响。

资料详情支持时，实际操作当前页资料入口、键盘打开/关闭及返回焦点、连续阅读和所声明的附录打印；复核展示方式提供短编号时再检查编号。没有页内编号或“范围与限制”页脚不单独构成缺陷。核对全文可达、引用版本与定位准确，真正影响判断的条件已由相关正文或图表标签表达。给AI的操作约束、材料转录说明和重复否定可以回到工作记录；不能仅凭它们在主画面消失就判遗漏。关系图须检查有效高度、图中文字观看尺寸、边是否穿过无关节点；容器未超框不保证内部图仍可用。没有执行某个状态就单独记未评估。

数值图表核对显示值、单位、零点、正负方向、缺失状态和标签区分；缺失不得补成零。折线核对真实序列、时间间距表达及缺口，不能把跨缺失的连线当已知趋势；热力矩阵核对行列含义、单元数值、图例色阶和缺失标识，不能只凭颜色作强弱结论。并排不等于可比，步骤不等于因果，层级不自动等于权责或价值链，面积/颜色也不能暗示未经证实的强弱。主辅空间、嵌套分组和跨面板对齐须有内容根据；布局树只证明空间安排，不能认证语义关系。影响判断的条件应在相关正文或标签中表达；单位、对象与状态清楚时，无须再加重复否定的小字。打印检查与屏幕检查分别说明范围。

每个问题给出可定位页面/元素、实际观察、依据和影响，再按 [审计判断](audit-judgment.md) 区分缺陷、必要证据缺口与可选建议。没有浏览器、截图或真实执行能力时，将对应视觉项记为未评估，不把源码、映射、渲染回执或另一份报告的截图计为通过。

## 输出与版本

先保存 `page-reading.md`（计划读取前的实际页面反读），再保存审计正文、必要截图/几何记录及真实检查。已有计划暴露时如实说明，不重写历史以伪造独立性。完成后用 [审计Run方法](audit-run.md) 检查审计自己的目录；结构通过、视觉判断和事实判断保持区分。必要内容检查未完成或仍有阻断缺陷时，不因HTML可打开而宣布可发布。

## 参考风格的适用检查

对用户已确认的[视觉方向](visual-editing.md)，检查浅色纸感、柔光、磨砂、圆角和轻盈正文在实际窗口下是否仍保留清晰层级与对比。普通页一个醒目主标题；封面/转场的巨型淡字或数字、轻微错位是可选节奏手段，不按装饰数量验收。定位任何背景装饰是否升级主张、遮盖图/限定、暗示未获支持的数量关系或稀释文字对比；需要减淡/移动/删除时给出具体元素与误读依据。不得为模仿参考而要求所有页面倾斜、重复大标题或增加截图。
