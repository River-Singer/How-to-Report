# 海报目录：三分钟交接初稿

## 汇报策略

采用用户已明确的目标：让两位接班者准确知道可供内部查找的条目、未完成部分和继续位置。两周接续已安排，不需要争取支持。中心问题是：**明天能用什么、遇到未核日期去哪看、接着做什么？**

从可用边界开讲，扫描完成仅作定位。接班者已经知道全部扫描完；真正需要补明的是“已录入”与“已通过复核”的区别。主线为：**128张已进入内部查找入口；其余112张有图像，但尚未通过检查，应按不同状态继续处理。** 不扩展为经费、采购、展示或个人成绩目标。正文外无新增沟通目标建议：现有材料已足以支持一次准确交接。

**B1｜0:00–0:50：哪些现在可用于内部查找？**

这四列是互斥状态，合计240张。原始阶段数为扫描240、录入180、检查140，彼此重叠，不能相加当成果。待修正12张仍未通过，不能与128张合并称为可用。[C1、D1]

**B3｜1:40–2:40：到哪里接、先处理什么？**

从共享盘 `catalog/index.csv` 开始，先处理 `fix_note` 中A箱8张、B箱4张，再按已有约定继续B箱、C箱。需要查图像时，按箱号和固定编号到 `catalog/raw/箱号/海报编号.jpg`；未通过条目的日期不可当作已核实，需要核对时回到原件。具体条目编号和修正内容以实际索引为准，本材料未逐条提供。[C1–C2]

**B4｜2:40–3:00：交接完成时应能定位什么？**

收束为“可用入口—索引标注—原始图像—既定顺序”。可请接班者指出未核日期与下一项工作的去处，以检查口头说明是否清楚；没有实际反馈，不能宣称他们已经掌握。范围始终为内部查找，未评估对外使用；没有耗时或使用调查，不报告节约工时或体验提升。[C2–C3]

模块关系：可用边界→未完状态→位置与顺序→交接核对。当前缺口是具体条目及备注；继续工作依赖已有索引，汇总表不能替代逐条任务。
