# 案例 02 原始材料

完全虚构，资料截止 2026-10-20 18:00。

## C1：目录口径

- 三个箱子共 240 张海报，每张一个固定编号，只计一张一次；CSV 单位均为张。
- `scanned`：有扫描图像。`metadata_entered`：有标题、日期、箱号三个字段。`qc_checked`：这三个字段已被另一位志愿者对照原件检查。
- `qc_passed` 与 `qc_needs_fix` 是这次检查的互斥结果，两者之和等于 `qc_checked`。需要修正的条目尚未复核通过。
- 扫描、字段录入、检查是同一批海报的前后阶段，彼此重叠；不能相加作为“完成工作项数量”。每箱符合 `qc_checked <= metadata_entered <= scanned`。
- 当前内部查找入口只纳入 `qc_passed`；没有录入或没有通过检查的图像仍可在原始扫描目录看到，但不能把日期当作已经核实。

## C2：保存位置与未完成事项

- 工作索引：资料角共享盘中的 `catalog/index.csv`。扫描件：`catalog/raw/箱号/海报编号.jpg`。这些是模拟材料中的位置说明，不要求实际打开共享盘。
- 所有待修正项已在索引的 `fix_note` 列标明：箱 A 的 8 张、箱 B 的 4 张。多数是手写日期难辨；没有统计每种错误的数量。
- 接班两周先处理这些标注，再按箱 B、箱 C 顺序继续。这个顺序是资料角已有约定，无须本次批准。
- 不提供耗时记录，不能计算效率提升或节约工时。没有使用者调查，不能声称检索体验已经提升。

## C3：边界

- 这批目录目前只作内部查找。公开展览尚未排期，资料中没有逐张对外使用范围记录；这不是本次交接要决定的问题。
