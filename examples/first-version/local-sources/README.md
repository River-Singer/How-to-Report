# 本地原文读取试用

[实际说明](note.md)由how-to-report包0.2.1、DATA-01/02卡片及来源归档0.1.1产生，使用[烘焙案例原始材料](../bakery/materials.md)和[数据](../bakery/handoffs.csv)。执行者实际读取了[政府数据质量正文](../../../skills/how-to-report/knowledge/sources/gov-data-quality.txt)和[NIST实验设计正文](../../../skills/how-to-report/knowledge/sources/nist-experimental-design.txt)的相关段落。

本地原文提供方法原则，案例材料提供业务事实；两者没有混用。原网址没有作为执行前提。正文为实际产物副本，仅将末尾trace指针改为任务验证目录的说明；冻结原件、读取范围、哈希和计算记录保持在Trellis中。

这是单独授权的模拟阶段，在新上下文外稿审计已完成并固定哈希后才发放；不追溯改变此前审计的知识范围。独立复核及限制见[第一版结果](../../../docs/first-version-results.md)。
