# 两周取货记录：可比范围与因果边界

可比较表内“已登记差错包裹÷交接包裹”：两周各七天、营业时长相同、包裹不重复，四组包裹数相同（B1）。实算W1为16/300=5.33%，W2为7/300=2.33%，下降3个百分点、少9包；这不是全部实际差错率。

分层结果：当面单品1%→1%、当面混装4%→2%、自助单品3%→2%、自助混装20%→6%。9包减少中7包来自自助混装。已知组别权重不变，仍不能保证组内品项数、顾客熟悉程度和时段相同。

通用依据：政府正文要求核对跨期定义，披露采集变化、缺失和重复[G]；它不证明本店数据真实或已发现所有差错。上述口径和数字分别来自materials.md B1及handoffs.csv。

NIST正文区分伴随变化与因果，提示第三因素并说明实验设计的作用[N]。本店新标签和货架分区同步改变，排班不同，另有活动客流线索；发现时点与发现人未完整标记，装包复核记录缺失（B1—B2）。因此只支持“W2登记差错较少，减少集中在自助混装”，不支持标签单独生效、货架是唯一原因、差错发生在装包或取货环节，更不能说问题已解决。需区分两项改动并补登记过程证据；当前没有已批准试验或额外工时（B3）。

[N] 本地nist-experimental-design.txt，30—34行。
