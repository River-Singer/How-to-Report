# 案例 04 原始材料

全部数据、机构、作者和引语均为虚构。材料截止 2026-10-20。

## S1：服务记录与口径

- “杉径种子角”借出小包种子，居民可用二维码或纸卡登记。没有要求居民归还同一种子；本记录不含种植成果。
- P1 为 2026-08-24 至 09-20，P2 为 2026-09-21 至 10-18，各四周。开放小时数相同。
- CSV 的 `digital_loans`、`paper_loans` 单位是完成借阅手续的笔数，不是独立居民人数。一笔只用一种登记方式，两栏无重叠；同一个人可以多次借阅。
- `new_member_accounts` 是期间新建账户个数；没有记录后续使用，也没有按年龄分组。
- `desk_volunteer_hours` 与 `offdesk_volunteer_hours` 是无重叠的志愿者工时。前者为现场值守，后者包括补录纸卡、补标签与盘点。它们不是付费员工工资，也不是开放小时；两人同时值守一小时算两志愿者工时。
- 两期都没有金额支出/收入明细、薪酬支付、满意度问卷、信任度测量或种植成功数据。

## S2：过程备忘

- P2 第一天把二维码放大并放到桌边；同时把纸卡盒从桌面移到桌后，取纸卡需要向志愿者开口。
- P2 的第一、第三周各有一场附近学校的参观，参加者可以借种子；没有单独标记哪些借阅来自参观。
- P2 取消了一次双人值守时段；开放总时长不变。协调员说随后补录和盘点集中到闭馆后做。
- P2 问询本记录 36 条问询，其中 17 条要求纸卡或更大字号的操作说明。这是问询次数，可能来自重复来访者；没有年龄、是否完成借阅或未借原因的系统记录。
- 六条匿名自由备忘中，一条写“忘带手机，等别人拿了纸卡”；一条写“屏幕上的字不太看得清”。备忘未随机抽样，不能代表所有居民。
- 计划：下月继续现有一个点，纸卡盒放回桌面；保留大字号说明。协调员已经安排两周观察两种入口的使用与未完成问询。没有扩到其他街区的批准或预算。

## S3：撰稿委托

- 给外部撰稿人的任务是本月开放日通报，包含使用情况、问题和既定下一步。
- 没有委托撰稿人替居民判断动机，也没有要求论证数字化方案胜出或申请扩点。
