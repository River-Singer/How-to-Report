# 合成演练：协作项目素材
委托者是项目助理，实际汇报者是项目负责人。业务团队整理计算规则和核对清单，技术团队按规则开发内部工具。项目负责人负责协调需求与检查节点；没有证据说明他独立完成全部编码。

当前工具已在试用环境部署，正式验收资料本次未提供。已支持成本归类和差异清单输出，业务人员反馈问题后由技术团队修订；未提供节省工时或金额数据。

第一场景：负责人明早向分管领导作约30秒口头更新。第二场景只有在后续明确提出时才适用。

同时有两项并行工作：业务团队整理规则库供人员培训，技术团队开发核对工具。资料没有说明规则库整理必须等工具完成，或两项工作互为前置。工具开发内部需要先确认计算规则，再实现对应计算；业务反馈的时间会影响部分修订进度，不是所有开发活动的唯一前置条件。
