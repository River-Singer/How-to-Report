# 0.7.4 定向回归与能力保留

四组9轮，候选版，模型由用户运行。01听众2轮、02进度2轮、03培训比较2轮、04审计3轮。全部建立在已见输入上，是已知问题回归与能力保留；不称新材料、独立保留集或盲评。没有匹配基线、重复采样、稳定量表或真人试读，不计算版本提升率或统计方差。

每组一个实际持续会话；逐轮只提供当前请求、列出的输入和本版Skill，不能发controller、评分条件、未来提示或别组产物。保存全部实际回复及问题；缺事实答未提供，不编补；额外往返、重试和中断如实记录。会话方式只能按实际选择一个：persistent、handoff、mixed或unknown，可得宿主ID及读取轨迹附位置，未知不伪造。不将模型自报当独立轨迹，不保存私有思维链。

02只验证初稿与部分回复后的完整更新，不重复上一批已正确完成的明确改期限第三轮。04首轮仅正文，第二轮来源，第三轮作者说明及待核旧意见；初读简述实际含义，不要求长篇自检。旧意见并非本轮模型的历史，不能要求模型为自己未说过的话道歉；其上轮若犯同类错误，也必须更正。

评审先读当轮来源形成可接受的编辑参照，再读产物。区分任务/事实错误、影响理解的表达差距、合理替代与有效表现；不强制操作链或标准措辞，不按缺陷数合总分。核状态及对象范围：未完成不等于未开展，未提供记录不等于没有做过，要求只说某件事不等于确认其他事情未发生。整项行动一起核对，标题、日期栏和正文不能各自成立而合起来矛盾；条件估计、请求答复期限和决策触发条件分别核。

审计按现行正文逐项处置：建议状态已经明确时，缺重复标签本身不是缺陷；如确有范围或归属问题，另以对应证据说明，不能借其保留原错误指控。必要条件不是充分保证；自然先后建议不自动是硬禁令；范围未定义时区分待核与确定矛盾。更正核到解释、影响、修法、替换句和总结。首读应与原稿复杂度相称，不靠多个重复摘要制造完整性。

公开输入全部合成；私有01/02使用已授权项目资料及明确演练，不发布。Q1—Q8沿用项目语义；must/must_not只供评审，工程程序不裁决语义质量。读取示范由Skill自身路由，不把预期答案作为额外提示；追加干预须另记，不能覆盖本批。
