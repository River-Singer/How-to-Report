# 港湾服务台规则说明活动（独立合成）
pr-demo@1。组织更改预约规则后举办一次说明活动，目标是让受影响服务商准确理解两项新提交要求。活动文章有1万次展示、1200次点击，线下有45人参加，无法与线上去重。会后20份自愿反馈中16份能正确说明两项要求；会前没有同口径测量，不知道反馈者是否代表所有受影响服务商。
活动后收到11项咨询，7项是填写细节，4项是资格条件；没有服务商信任调查、实际提交正确率或收入测量。业务方同期简化了申请表，尚未分离其影响。新闻稿草案写“全面赢得信任、彻底消除误解”。对外可公开新规则和上述活动统计，不能公布服务商姓名。
我代表传播团队向委托部门做八分钟复盘，想让他们准确判断活动做到哪一步和是否继续解释容易混淆的要求。部门负责人决定是否继续投入沟通时间；传播负责人评价受众理解与消息准确；业务规则负责人确认规则含义，没有人为信任作过测量或授权收入承诺。
