# 图书馆检索助手试用记录（合成）
用途：帮助值班馆员根据读者需求，从已经整理的馆藏目录中找到候选书目。业务小组编写分类规则并核对目录字段；开发人员把目录查询和分类规则封装为可调用工具；语言模型判断先按主题还是作者查询，并组织候选结果；馆员确认推荐给读者的书目。
试用只覆盖一个分馆的两类借阅咨询：按作者查找和按主题找入门读物。3名馆员记录20条咨询过程，其中15条产生了候选书目，5条因读者要求不清而继续询问。候选书目不等于推荐正确或借阅成功，未做正确率或耗时对照。
目录更新仍由馆员维护。新分类规则要由业务小组确认后交开发调整，系统没有自主更新规则。当前工具只能检索已整理目录，没有跨馆实时库存功能。试用结束后，馆长希望讨论是否值得在另一个分馆进行同类小规模验证，尚未批准。
