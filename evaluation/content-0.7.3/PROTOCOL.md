# 0.7.3 定向回归与能力保留

四组10轮，候选版，模型由用户运行。01听众2轮、02进度3轮、03培训比较2轮、04审计3轮。全部建立在已见输入上；03本轮也是保留验证，不再标作新材料或独立保留集。没有匹配基线、重复采样、稳定量表或真人试读，不计算版本提升率或统计方差。

每组一个实际持续会话；逐轮只提供当前请求、列出的输入和本版Skill，不能发controller、评分条件、未来提示或别组产物。保存全部实际回复及问题；缺事实答未提供，不编补；额外往返、重试和中断如实记录。会话方式只能按实际选择一个：persistent、handoff、mixed或unknown，可得宿主ID及读取轨迹附位置，未知不伪造。不将模型自报当独立轨迹，不保存私有思维链。

02第三轮是明确改变仍待答复事项的期限，局部更新受影响文字，不重交无关页。它不是新申请日期自动取消旧请求的情境；这个区别由评审核查，不提前教给生成者。04首轮仅正文，第二轮来源，第三轮作者说明及待核旧意见；初读简述实际含义，不要求长篇自检。旧意见并非本轮模型的历史，不能要求模型为自己未说过的话道歉；但其上轮若犯同类错误，也必须更正。

评审先读当轮来源形成可接受的编辑参照，再读产物；已知问题和先验暴露如实记录。按任务/事实错误、影响理解的表达差距、合理替代、有效表现分别描述，不强制操作链或标准措辞，不按缺陷数合总分。必要条件不是充分保证；自然先后建议不自动是硬禁令；范围未定义时须区分待核与确定矛盾。重要修正核到当前有效建议及总结，不只看是否说过道歉。

公开输入全部合成；私有01/02使用已授权项目资料及明确演练，不发布。Q1—Q8沿用项目语义；must/must_not只供评审，工程程序不裁决语义质量。读取示范由Skill自身路由，不把预期答案作为额外提示；追加干预须另记，不能覆盖本批。
