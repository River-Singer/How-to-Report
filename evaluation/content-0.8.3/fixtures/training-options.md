# 售后人员培训：会前记录（合成材料）

这些是供本轮汇报使用的演练事实，不对应真实企业。

1. 现有两种候选安排，均覆盖同一个月，均讲新设备的故障判断和维修记录。预算包含讲师、场地和器材，口径相同，未包含参训员工工时。
2. 集中讲座方案：两场，每场40个名额；每场半天，先讲判断思路再答疑；预算9000元。两场共80个参训名额。
3. 分组实操方案：四场，每场12个名额；每场半天，由学员在样机上排查问题并填写维修记录；预算10800元。器材限制每场人数，四场共48个参训名额。
4. 业务经理说门店覆盖面很重要；现场主管希望能观察学员是否会排查和记录。两项需求并不互相否定，目前没有确认优先级。
5. 本轮报名名单尚未确定，尚未收集培训效果数据，各门店能否腾出半天也需协调；两种方案都可报名后分配场次，不需全店同时停工。会前材料没有门店人数和排班表。
6. 负责人可决定采用哪种安排，但还没有批准任何方案，也未授权追加预算。尚未取得讲师混合授课报价。
