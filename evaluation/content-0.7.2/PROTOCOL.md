# 0.7.2 定向回归与不同材料迁移试测

四组12轮，只有候选版，用户运行模型。01/02使用已见资料作回归，03使用新合成的培训安排比较材料，04沿用已见审计正文并增加条件句对照。03不是独立保留集或盲测：输入由开发侧依据研究问题设计，不能据此声称未见泛化已验证。私有01/02使用已授权项目资料与明确演练，公开版全部为合成。

每组一个持续会话；逐轮只发当前请求及列出的文件，不发controller、评分项或未来提示。会话若中断或以新agent交接，如实记录已带入内容，不把handoff说成same_conversation。保存全部实际回复及提问，不能挑最好一稿。缺少事实就答未提供，不编补；操作性答复与修改预定用例须记录，不冒充原设计。

01第三轮只改第1张主材料页的标题；02第三轮只精简实际最后一张主材料页，未假定它含请求；03第三轮只改第1张主材料页标题。模型须沿用实际页号/标题定位，不改变其他内容。若前轮未产生主材料页，记录无法执行，不能由操作者伪造页面。04第一轮只读正文，第二轮读来源，第三轮开放作者说明和旧意见；接触作者信息的范围如实披露。

方法读取有宿主记录时，保存实际文件路径、读取顺序和日志位置；不能取得则记unknown。自述读过不等于工具日志，日志没记录也不能断言未读。默认不额外指定某教学章节；如果另做显式示例干预，应另存附加实验，不能覆盖本轮。03观察解释/比较能否适应不同用途，不按是否复用示范句型评分。

评审先按当轮来源与请求形成编辑参照，再看产物；已知问题背景与先验暴露如实记录，不声称完全盲评。检查读者能否回答本次问题、事实条件保真、修改范围、审计指控是否成立；标题/措辞/合理页数允许替代。参照错误另记撤回，不倒改成事先正确。分别记录任务或事实错误、表达差距、合理替代及做得更好的地方，不按缺陷数或模板关键词合成总分，不计算未经校准的方差/提升率。模型反读不等于真人理解实验。

Q1目标、Q2区别与判断、Q3证据、Q4叙事、Q5数值、Q6成稿、Q7交互、Q8范围与审计沿用项目含义。must/must_not只供评审；工程验证只检查隔离、版本及文件完整性，不裁决语义质量。
