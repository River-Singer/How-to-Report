# 一次跨部门对账实践与合作会（独立合成）
personal-demo@1。我希望合作方信任我承担下一次小范围需求与验证规则梳理。会议对象是合作方业务负责人和技术负责人；业务负责人能决定是否安排业务人员参加下一次需求梳理，技术负责人决定技术联系人能否配合，不是招聘、晋升或采购会议。
我在这次实践中发现两部门对同一成本字段含义不同，整理了12项定义并主持核对；两部门负责人逐项确认定义，开发同事实作接口。按确认定义目前能复算三个样本。我没有独立开发该接口，没有测全量节省时间或财务收益，也没有证明其他业务通用。合作方有一项订单分摊规则需要核清，但还未给完整样表。我可以每周投入半天做两周的梳理；数据接入和业务签收需要双方确认。
