# 一次配置差额查看记录

来源身份：cost-pilot-demo@1的后续合成记录，日期12月7日。仅为本演练，不是生产使用或原项目业绩。

业务负责人希望解释甲与乙的两项零件合计为什么相差19元/车。成本专员打开build-03的P1/B2/C1样例结果，先读甲250、乙269，再展开支架与接头两行。支架从200变为224（差24），接头从50变为45（差−5）。展开结果行可以回到相应数量、单价与变化额记录。

核对员在本次操作中逐行复算了R1—R4，确认与上述结果一致。甲乙都按B2取支架2件/车、接头1件/车；支架差24来自单件变化额12乘2，接头差−5来自单件变化额−5乘1。本次没有检查R5/R6，也没有做新的导入顺序测试。业务负责人据此指出，本次两项零件差额主要来自支架，但没有据此决定整车配置。

会上提出将同样的差额查看用于另一车系；对方还未提供完整记录。本记录没有计时、参与者以外的用户反馈、前后效率比较或实际降本金额。
