# 操作者协议

模型由用户运行；组间新会话、组内真实连续会话。每次只发当前提示与所列材料；cases全表、coverage、评审参照、未来文件、旧结果不得给生成者或它派出的子Agent。原13组保留旧事实与续轮，但新确认职责仅为本轮演练，不倒写原项目历史。

09、14先保留实际澄清回复，下一固定轮才提供既定确认；不替模型补答案。需要额外澄清时只按已开放事实回答，未知说未提供，完整保存往返。13审计由主会话协调真实独立执行者，第一轮只正文；收到初读再给来源，最后给作者说明。初读时主会话也不要把后轮资料传入。无法独立委派或上下文分批时如实记未完成/暴露，不假扮、不新增服务。

按Skill正常选择相关知识；所有组许可按本案相关问题使用本地知识，许可不等于联网或读取其他组。任何额外宿主能力限制记录实际事实，不预设工具成功。两个明确不同独立职责分别派发可分批，不能用案例间分派充当单份材料内部委派。运行记录要保存调用ID/时间/返回、实际可读范围、禁止范围、失败或空响应、问题与主Agent响应/未决状态，模型自述单列。不得为填日志另跑模型。

用户不必先让生成者猜中新增材料；按固定轮自然发后续，不称其一定已提出该补件请求。每轮回复原样保存，不覆盖前轮。冻结前不运行；冻结后只在outputs新增结果，输入/提示/包保持原状。没有实际行为证据，不宣称真实委派、禁网、独立盲审或模型效果已经验证。
