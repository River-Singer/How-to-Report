# 操作者与评审约定

本文件及cases.jsonl中的must/must_not不提供给生成上下文。前两案旧新版使用相同输入、固定后续轮次和相同模型条件；组内延续同会话。中途不得替模型补想法或引用其他组答案。若模型提问，保存问题后按下一预定用户消息继续；无相关答案就明确未提供，不编补项目事实。

保留全部轮次，不挑最好的一轮。评审比较目标变化后的内容取舍、跨记录概括、必要条件、逐页可用内容与多轮联动；局部任务的输出范围同样重要。准确与有用分别评价；一个合理措辞不是唯一答案。独立审计意见还要回查原句，不能因来自audit就当真。

时间预算用于选材，不按固定语速判真实演讲达标。未做真人试读不称受众理解已验证。不能把工程校验当模型执行；每项结论须引用实际产物位置。Q1—Q8沿用既有项目维度，具体must/must_not为行为关注点，不是自动判分程序。

Q编号延续既有项目含义；只评价该案涉及的项目，依据实际输出记录观察，不自动合成总分。
