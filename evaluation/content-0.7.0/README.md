# 0.7.0 工作流评测输入

四个基础案例：混杂记录到逐页材料、实践到不同听众、局部修订、外来稿独立审计。前两案建议冻结0.6.1/0.7.0各一组，后两案仅新版，共六组；不执行模型。材料为原创合成开发输入，不是真实客户实绩，也不冒称盲测或未见泛化。

每组从新上下文开始，组内按轮次连续对话；不要同时打开cases.jsonl或未来补件。运行者只交当前`--case ... --turn ...`返回的任务与所列材料。审计先读成稿，再分阶段开放来源与作者说明。全部评分关注点仅供操作者/事后评审。

```text
python evaluation/tools/validate_content_cases.py
python evaluation/tools/validate_content_cases.py --case C070-MATERIAL --turn 1
```

命令只校验输入和展示当前轮，不调用模型。记录每轮实际输出、模型/设置、是否沿用同一会话以及使用的确切冻结包。只看语义变化，不用固定页数、标题关键词或猜中隐藏目标评分。见[评审约定](PROTOCOL.md)。
