# 0.7.1 定向回归评审

四案共11轮，只运行候选版。沿用已见材料以观察已发现问题，不宣称未见泛化或总体版本提升。输入设计与私有项目案例分开；批量模型运行由用户执行。

操作者逐轮发送当前提示和列出的文件；组内使用同一实际会话，不因进入下一轮新建agent。若宿主只能交接续作，如实记录，结果仍可审，但同会话连续能力未验证。未知模型设置写未知。完整保留所有轮次，不挑最好的一次。

评审在读输出前，只按每轮已经提供的事实和任务写编辑参照：要完成什么沟通、哪些内容必需、哪些可舍弃、可接受的路线。允许多种标题/页数/措辞；参照有误单独记更正，不追改为仿佛最初就正确。先读各轮实际产物，再对照来源和参照，区分事实或任务错误、影响使用的表达差距、合理替代以及优于参照之处。不得用audit缺陷数或通过标记直接计分，也不计算未经校准的方差或提升百分比。

01关注业务过程、参与方式和有依据的下一步；02关注补件是否改变判断和安排；03关注标题与正文分工及修改范围；04关注审计复述、缺陷裁决和修复句各自的来源依据。没有一个统一的标准答案。未做真人试读，不称听众理解已验证。

Q1目标、Q2区分与判断、Q3证据、Q4叙事、Q5数值状态、Q6成稿、Q7交互成本、Q8范围与审计，沿用项目维度但不自动合成总分。must/must_not仅供评审，不能发给被测模型。
