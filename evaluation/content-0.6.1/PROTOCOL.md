# 0.6.1 自然输入与条件变化评估

本协议只规定输入和观察方式，不宣称模型行为已经改善。案例全部为合成的开发集；不以猜中隐藏动机、出现方法名、固定结构或指定措辞评分。

## 运行与隔离

`dataset.json` 固定本目录说明、协议、空白记录、案例目录及全部材料的 SHA-256。执行前核对当前输入和冻结 Skill 的 manifest，留下实际模型、工具、权限及上下文暴露情况。三组分别在新上下文开始：`plain` 使用普通任务提示；`skill-0.6.0` 使用冻结旧包；`skill-0.6.1` 使用冻结新包。三组的任务、材料、模型设置、预算与允许工具相同；普通组不故意使用低质量提示。若条件不同，分别描述，不宣称对照增益。

运行者用 `validate_content_cases.py --case ID --turn N` 提取当前消息与材料清单，再将这些内容交给执行模型。模型不可读取案例 catalog、评审条件、协议、未来补件或其他组输出。只在保存本轮实际输出后释放下一回合；后续材料不得回填早期输出。通常同案同组续接原上下文，若换上下文要记录继承方式。若模型提问，先保存；下一阶段已给的自然回复按时释放，其他问题由运行者如实回答或记录信息不可得。不能根据评审条件提供暗示。

审计案第一回合只有待审正文，保存读者理解；第二回合增加实际任务与来源，保存独立判断；第三回合才增加作者说明和旧意见。第三回合同时观察是否纠正错误、是否盲从旧意见，不把改判本身当退步。其他生成案例若再加独立审计，审阅者先只接收正文，再接收任务和来源，最后才接收作者工作说明；不要把整份含自评的文件伪称为正文先读。读过资料的审阅者不能重新自称盲审。

记录实际输入、输出、澄清、版本和工具结果；没有计量就把 Token、费用或耗时写未知。无需私有思维链。批量运行由用户操作，不调用本机模型或 API 自动复跑。审计或修订的额外成本独立列出，不混入三组首次成稿成本。

## 看什么

先隐藏组别看稿件实际表达，再看任务和来源，最后看作者说明。允许多个合理结构。每个缺陷、资料缺口、可选建议都需实际位置、依据和影响；不以有无免责声明或某个词裁定。数值、时点与必要/充分条件按实际命题检查。不能用加权均分抵消重要事实错误。

| 维度 | 观察 |
|---|---|
| Q1 目标 | 不确定结果是否得到有用处理；已明确的目标是否控制主次与结尾 |
| Q2 区分与判断 | 是否保留改变判断的重要区别；信息不全时有没有有依据的有限建议 |
| Q3 证据 | 对象、范围、归因、状态、条件与真实资料一致；缺资料不等于没有发生 |
| Q4 叙事 | 顺序帮助理解，保留并行、反馈和依赖，不在总结时增添保证 |
| Q5 数值与状态 | 同口径计算，区分已逾期与未来预测，不虚称执行 |
| Q6 成稿 | 指定汇报者能直接使用，必要背景足够，作者工作说明适量 |
| Q7 成本 | 提问、分析与附注是否值得，短任务有没有徒增往返 |
| Q8 范围与审计 | 局部改动守范围；审计能识别真实问题，也不编造误报 |

可按 0–4 描述适用项（0 相反或缺失，1 明显不足，2 重要缺口，3 满足，4 有明确额外价值）；评分非必填，不适用单列。必须同时记录真实错误、遗漏、有用内容与交付负担，不能只评价安全谨慎或篇幅短。

## 案例判读补充

- GOAL：首轮没有唯一正确隐藏目标；合适的澄清或可逆暂定方向都可。第二轮协调、第三轮复盘应产生内容责任的变化；没有审批过程记录时，不编责任结论，也不因此放弃已知偏差说明。
- JUDGMENT：更多开发人员不能替代取得样机。第二轮可改变下一步动作，但两项安排落实仍不能推出适配完成日；不重问已经明确的会议目标。
- LOCAL：观察替换句是否清楚且保真、交付是否直接；不要求“必须再改”，也不因有一句有用说明扣分。第一轮句子合适时第二轮保留即可。
- RELATION：重要对象由听众与用途决定；不能只凭缩短率评价。省略一项无关细节可以，删掉解释实践所需的协作或混同两类成果需要说明影响。
- TRANSFER：无收益台账仍能说明用途和反馈促成的修改。第二站点缺统一分类与参与时间，可据此提出待核对问题和小范围探索建议；不能把观察到的条件变成通用硬门槛，也不能以单样本为由拒绝一切适用分析。
- AUDIT：联调已过原定日仍未完成，现有逾期成立；最终完成日及总偏差仍未知。第二段把必要条件写成日期承诺、第三段把未取得工时写成没有记录，是可定位的缺陷。职责说明不能自动解释成已验证稳定性；项目方尝试其他门店的判断有来源，但不是独立复制试验。“候选”修饰对象不明，宜保留歧义，不能宣告标准未批准。旧意见故意同时含漏报和误报；核对的是其实际主张，不是反驳全部旧意见。

案例允许多种建议与语言。这里给的是判读边界，不能成为执行模型的答案提示。结构与哈希检查只证明输入正确、分阶段提取无评审字段；不能证明执行者没偷看、模型理解正确、真实受众读懂，或本版收益已经验证。
