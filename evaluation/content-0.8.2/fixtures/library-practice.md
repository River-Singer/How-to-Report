# 滨湾图书馆问询助手：实践记录（合成）

这是新编的虚构项目记录，供公开方法评测使用，不对应真实机构。

## 用途与实际操作
两个值班台接收读者的作者、主题和阅读程度描述。馆员将需求输入助手；助手查询已整理的馆藏目录，给出候选书目、目录字段及检索理由。馆员检查书目是否符合需求，再向读者推荐。目录中的馆藏位置可用于找书，工具没有实时借还库存数据。
目前试用仅覆盖按作者找书、按主题找入门读物。20条咨询记录中，15条返回候选书目，5条因需求含糊继续询问；这些记录未附实际借阅结果或耗时统计。

## 分工与工程做法
两位值班馆员共同整理分类词与例子，复核目录字段及推荐理由；一位应用开发人员维护查询接口，一位平台工程师维护部署与日志。应用层先用结构化字段检索，再由语言模型组织候选说明；查询不到时返回无候选，不新造书目。馆员仍负责面向读者的推荐。
一次联查发现旧目录中的同名作者被当作同一人。馆员补充作者标识示例，开发人员调整查询条件，再用该例复查，保留了问题与修订记录。没有附完整质量测试结果。
新增分类词由馆员提出，经业务小组确认再交开发修改。目录每周人工导入一次；管理员可停用助手，改回原目录检索。本批未附故障演练、全链路安全审查或完整维护成本记录。

## 范围与下一步
项目团队称试用工具已经可供两个值班台内部使用。语言模型服务部署在馆内服务器；这条记录只描述该组件位置。当前未打通跨馆库存，团队提出进一步核对另一分馆目录字段后再评估试用，尚未获得对方参与安排。
近期还提出按读者年龄段辅助组织入门书单；这只是候选方向，没有实现或效果记录。团队没有提供收益台账、跨馆推广批准或维护预算额度。
