# BUS-02 替代方案与机会成本

版本：0.1.1。核对：2026-10-26。可选经济商业卡，仅在许可覆盖本卡时读取。

## 何时用、需要什么

用于选择、优先级或“为什么采用这个方案”的主张。需要目标与硬约束、实际可行选项、资源用途和关键不确定性。只同步事实时不强迫用户做方案比较。

## 执行动作

1. 根据问题寻找真正可替代的行动；把继续现状视作一个可解释的参照，现状会怎样变化不能默认等于零。不要为了显得周全制造不可行陪衬方案。
2. 找能改变取舍的差异：解决哪个问题、耗费什么稀缺资源、放弃什么可行用途、哪些条件决定能否实现。机会成本是因当前选择而放弃的最佳可行替代用途的价值，不是任取另一用途，也不是将所有未选方案损失相加。
3. 区分已不可改变的投入与接下来仍可改变的成本。过去花了多少可以解释背景，不能单独证明继续投入更好。
4. 对关键分歧给出“在什么条件下会换选项”的问题和证据需求；把价值偏好、事实估计和权责分开，不能用模型自定权重替用户选择。

## 交付与独立审计

输出与同一目标有关的选项对照、重要条件、取舍理由及待决定事项。若主要条件未明，交付条件性建议或补证任务；不保证存在唯一最优方案。

审计寻找被遗漏的可行替代、失真的现状参照、重复成本、沉没成本绑架及未经确认的优先级。方案换名称但实质动作一样时，应合并；不同目标的方案不直接按一个收益比排名。

停止于足以说明本次选择的实质差异，不展开与当前目标无关的全量战略分析。
