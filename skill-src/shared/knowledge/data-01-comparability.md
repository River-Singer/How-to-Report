# DATA-01 比较口径与聚合

版本：0.1.1。核对：2026-10-26。可选统计数据卡，仅在许可覆盖本卡时读取。

## 何时用、需要什么

用于跨期比较、比例、汇总或多表合并。需要原始数据或可检查明细、字段含义、纳入规则、期间与版本。只拿到汇总图时，可检查其声明口径，但不能假称已经核对明细。

## 执行动作

1. 先说明“一行是什么”“数的是什么”，再核对单位、时间边界、总体/样本、分母、重复、缺失与排除规则。未知值保留未知，不能补成零。
2. 比较两组时先找口径变化：对象、分类、采集方法、样本构成或覆盖范围是否变了。若不同，优先求可比子集或分别展示，而非直接合并。
3. 比率写出分子与分母并实际计算；合并时使用适合该指标的权重或原始计数，不能无条件平均百分比。事件次数、用户数与交易数不能互换。跨期开始和完成需要匹配规则，不能默认同月两数来自同一批对象。
4. 逐步检查聚合/连接前后的记录数与总量，解释变化。若只看总数会掩盖重要差异，按有依据的单位或群体拆开；拆分是发现机制的线索，不自动说明原因。

## 交付与独立审计

输出口径说明、真实计算凭证、可比较范围和会影响结论的缺口。审计独立重算关键数值，检查丢失记录、连接重复、分母改变及平均掩盖；数据完整和格式有效仍不证明事实准确。

缺少关键分母或纳入规则时停止百分比/排名结论，可以先交付描述与补数请求。不要为了图表完整补造数据。
