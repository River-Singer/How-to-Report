# 从零散记录到有内容的概括

本方法负责来源提炼、关系辨认和含义保真，不负责整场叙事或执行顺序。记录多而杂、概括缺少解释、同主题状态不一或压缩可能改义时使用。简单清楚的句子直接编辑。

## 找出本次问题需要的记录

围绕已采用的听众问题，辨认谁对什么做了什么、现在是什么状态、相对什么参照，有哪些解释、条件或请求。按意思辨认，不按标点拆句，也不要求每条填满字段。保留可回取的材料定位；材料未说、相互冲突和范围不明都不能改写成确定事实。

对聊天、改稿和多版材料，核原句的说话者、活动对象、适用范围与后续更正。历史“我”不自动是当前汇报者；工具名、旧稿署名或角色代言不证明实际职责。编辑图稿与管理图中机制是不同活动，前轮模型建议也不因换业务代表就成为“技术侧提出”。切换身份只改叙述侧重，不增加亲历、转移归属或恢复旧职责。已有个人判断、推进与协作作用应保留；身份确实影响个人贡献页且资料不能确定时才问，其他地方可用有据的团队或职能表述。

来源声称的关系、当前推测与已经核验的关系有不同身份。原文写因果只证明它这样声称；缺乏关系支持时不要自动降格成“相关”或“可能影响”，因为二者仍声称关系。可分别写事实；确有假设则保留其假设身份。

## 从图像中读取可用信息

实际读数之后，按[业务数据分析](business-data-analysis.md)寻找与本场问题有关的变化、群体差异、层次与交叉关系，完成可行比较与派生核算，再说明这些发现对业务意味着什么。数据图像可提供分析输入，成品按听众需要重新组织可编辑指标、图表或图形。

材料中的图表、看板、截图与正文共同提供依据。用户已说明图片用途时沿用，其余按本场听众任务判断它承担数据来源、证据原貌、界面演示还是视觉素材。实际查看相关原图，读取与问题有关的数字、单位、比例基数、期间与筛选范围、图例、对象和关系，保留能回取到该图或区域的位置。文字提取结果可辅助定位，重要图像信息仍对原图核准。

先辨图内各部分及正文的口径，再判断是否可比较、合并或构成冲突。明示的精确读数按原口径使用，可辨识而无精确标注的变化用趋势或注明约值表达。转为新图时保留读数的精度身份，精确序列需有可读数据支持。读取受清晰度、裁切或工具限制时，指出影响哪项判断及所需的清晰区域，保留当前已能支持的内容。

图片承担数据输入时，将提炼出的信息写进当前正文与判断，再按媒介与使用要求选择数字、表格、数量图或关系图等表现。制作可编辑PPT时，让提炼后的数值、标签与关系进入相应文本或数据对象。图像作为证据或界面展示时，按听众需要保留原貌及必要说明。制作选择由信息用途决定，原图继续可供回查。

## 跨记录归并，再写统摄句

先问这些记录共同回答什么：覆盖了哪些对象、哪项工作到了什么状态、阻碍是什么、采用了什么做法，还是哪个选项更合适？同词出现不等于共同回答；同一事项散落不同段落也可以归并。

1. 找出可共享的背景，合并重复记录；保留会改变判断的对象、状态、例外和条件。
2. 用统一的问题或比较标准组织一组信息。为听众补出资料已支持的对应关系：什么输入经过谁的处理成为何种结果，哪些选项按同一标准比较，或哪项未决影响哪项安排。事实、条件和请求可以共同回答“下一步如何推进”，不必为分类纯净拆散；但不得把工具、活动和预期收益伪装成同级已实现成果。
3. 用自己的话写这组材料共同说明什么，再回查每个组成部分。概括可以是原文没有的统摄句，但其含义必须由已有材料支持；不能借“重新组织”新增事实。
4. 保留支撑或区分概括所需的细节，移走不服务本次问题的分类。细节可以是一项操作、一次对照或一个关键例外，按本次问题选，不是只保留异常、亮点或数字；少数例子也不代表穷尽全部类型。是否已让听众理解，由主工作流用实际成稿检验。

例如“一线访谈已完成、规则清单仍在定稿”可以归为需求工作进展，不能缩成“需求已确认”。“积极开展调研”只是抽象标签；覆盖谁、发现什么、哪些还未定，才构成有内容的概括。一次访谈与一项规则不是同一计数单位，不按行数或共有主题相加。

删除前检查该信息是否支撑后续判断，或使听众能够理解、核查、使用它。可以删无关明细，不能只因最终建议不变就删掉必要解释。标题、表头可以承担共有对象和期间；内容被独立摘出或转成口头稿时，要补回缺失的上下文。连续过程见[合成教学](content-decisions.md)。

## 把概括展开为可理解的关系

“实现数据协同”“支持变更”可能是概括，却还没告诉听众具体怎样工作。沿当前判断找尚未回答的必要问题，再回资料取出对应关系。流程解释交代输入怎样变化、谁处理、何种结果可用；差异解释交代同一对象在什么条件下为何不同；采用建议交代可用范围、证据及仍需满足的条件。按实际困难选，不给每段套全套项目。

具体化时先用适用记录把一个对象或实例讲通，再说明它支持哪部分判断。每接入一条关键关系，就对照这条关系的依据：已有观察怎样支持结果，规则怎样解释差别，建议为何值得采用。遇到版本、实施状态或归属跨接，先按下文[共同标准](#含义保真的共同标准)修当前段，再继续展开；不能把名词相同的记录先拼成完整故事，最后才补限制。设计可解释拟怎样运作，观察只说明所覆盖的实例；一项实例可以讲清机制，不代表全部场景或已实现收益。

子问题有据的依赖要连起来，不能把规则、实例与结果留给读者拼接；只有记录日期先后，就按发生次序叙述，不补成全链前置。检查日志要说明哪项观察支持哪个判断、适用哪个版本，整表照搬不能代替这层解释。一项比较可以包含多个对象，必要过程也可分段展开。见[丰富资料的短长对照](../assets/examples/report-depth-proposals.md)，页组位置由[会议表达](meeting-expression.md)决定。

## 从概括形成判断与建议

概括写清材料共同说明的现状、变化或关系，再解释它对本次业务任务意味着什么。规律、比较和机制可以支持汇报者形成新的判断，判断的依据与成立条件须接得上。批准状态、总体风险和已实现收益等结论分别按其实际依据核对。

后续建议可以在事实与本场目标基础上构思。按需要说明针对的对象、拟采取的方式及预期作用，检查本场阶段所需的可行性与配合条件。整段已交清建议身份后，可直接说明拟做的动作，实际资源、责任和承诺日期按已知状态表达。

核对概括看记录支持的含义，核对推断看证据与推理连接，核对建议看问题、目标及适用条件。将困难解释、用途与建议交给[论证方法](method-argument.md)。主动新增区别的检查与深化由[解释探索](insight-discovery.md)承担。保留影响判断的反证与有依据的用途说明。

## 含义保真的共同标准

生成、编辑和审计共用以下对读方法，用于重要的新概括、改动或疑点；顺序由主工作流负责，不逐句建账。

1. **先确定来源实际支持什么。** 打开疑点所在的完整句与相邻限定，再回原记录及适用更正。暂不沿用旧稿结论，用普通文字说清来源中的谁、对什么、在何时/哪版做到了哪一步；聊天还要核发言身份，不能只截一句内容。分开来源明确给定、没有提供和我们新增推断的部分，只保留会改变判断的范围。说不清的部分保持未知；明确给定的观察按其原范围保留，不靠名字或数字拼接，也不以缺方法附件为由自行取消观察。这里只是当前编辑动作，不另交事实表。
2. **把新增的解释和理由接上。** 将稿句相对上述意思多说或少说的部分找出来：是否增加了实施、历史否定、覆盖、排期、唯一性或因果？决定性条件是否丢了？每个实际采用的补强都须另有依据；推荐本身成立不替其他理由作证。必要时试一个“来源仍真、稿句却假”的相容情形来定位问题；想到反例只揭示差别，想不到也不等于证明成立。
3. **修可用文字，再查仍生效的同一判断。** 保留有据事实、解释与选择，删去多出的断言，或将确属建议的部分写成建议；必要缺口具体提出。缺记录时写清本轮尚不能判断的事项，不能将“已验证”反转成“从未验证”。回读新句与依据，再沿受影响的标题、正文、讲解、备查及作者摘要核同一判断，防止下一轮又从错误摘要恢复旧说法。只处理依赖此判断的位置，不强行统一措辞或重写全稿。

对读时按实际变换使用下列标准；不要求每句走全表。有据解释、带假设的预测与明确建议均可保留，困难推论用[概念](method-concepts.md)或[论证方法](method-argument.md)。

- **对象与归属**：保留行动者、活动对象及组件边界；把历史行动写成本人贡献前，先核实际归属，当前代表不增加历史成员。观察、设计与建议跟着对应版本和原说话者；旧版数值仍适用也不自动迁移“新版已核查”的资格。助手建议与待建设能力不能仅凭同主题或旧稿复述升级成现有实施。
- **状态与范围**：保留完成、进行、拟议、预测、待答复，以及数量、期间、部分/全部和频率。未附记录不证明未测，未获答复不证明未安排，未完成不排除已开始；禁止正面断言也未确认相反事实。已给样本结果不因缺少额外认证被降成“结果尚未认定”，是否能外推或归因另核；有实际冲突则按证据重判。“下期”不能变“本期”，区间内事件不补成某一日。写“逾期、未兑现、未按期”前，对齐当前观察截止日与所述期限。期限未到时，按来源写尚未收到、预计后移或原预测已调整，历史预测后移也不证明此前各次预测都已失约。完成终点有验收要求时，提交或记录齐备不能改成验收完成。
- **比较与计量**：保留单位、基线、定义和相同所修饰的对象；费用项目相同不说明预算足够，接入数量相当不说明工作量相当，容量不证明实际覆盖。两个正确数字不自动可合计；数值与待定状态不能统称同类数值。日期差不自动是工作量或历史估算。按[数值方法](numeric-evidence.md)核算有定义的量，并对读采用该数值的比较词与推荐；一个约束已满足不证明所有标准均优于替代。
- **关系**：方向及依据须匹配。时间先后不证明依赖或因果，角色列表不说明执行频率或流水线顺序，相似职责名称不证明已有冲突、须由领导裁定。两个前提并存不说明互为前提；多项同时变化，不能把提升的一部分直接分给其中一项。已知阻碍不必是唯一原因，“增人不能替代批准”也不等于“与工作量无关”。已有且影响行动的依赖应保留，不能删成互不相干的状态；相关也不是同义。
- **条件与强度**：分别核必要性和充分性，“满足后就能”与“全部完成后才能”都需依据。预测、用途与职责分别不变承诺、实绩与结果保证。例子或局部检查不扩为全体能力；机制说明不变效果证明。可以按适用假设提出估计，不因尚未完成而禁止估计。
- **请求与意见**：知悉、建议、批准请求与已授权行动有不同含义。协调、提交申请、审核和批准分别核实际主体与授权，来源说负责人能联系接口或提交申请，只能据此表述相应动作，审核、批准及替他人承诺的权限另需依据。共用期限约束的余项仍保留；收到答复、条件满足、计划可执行与备选触发分别核据。新增跟进可以是建议，不能冒充原请求的前置或权限；未收到异议不等于已获同意。允许附条件决定时保留这一可行方向，同时交清什么条件会改变金额、范围或再次报批，不能由“已有归口”推出未知不再影响决定。来源意见也不变作者独立验证。

保留影响本次判断的反证和正式必答。上层标题和结尾应受下层内容支持，流畅和句式平行不证明含义未变。不要求逐字保留，也不禁止正当专业词。发现问题修最早出错的归并、关系或概括，不用末尾免责声明替正文纠错。叙事/详略由[会议表达](meeting-expression.md)负责，措辞由[观众编辑](audience-copy.md)负责。

### 缺材料与已给观察，向两边都要保真

以下是合成培训反馈：记录明确写“受访者中有九人能正确演示归档步骤”，没有提供前测或判定细则。可写“这次访谈中，九人能正确演示归档步骤”；不能改成“九人只是在复述讲师的话”，也不能外推为“培训使全员掌握归档”。前者擅自削弱已给观察，后者新增总体与因果。若本场要证明培训提升，再求同口径前后观察；只是同步当前样本表现，就不新增“主管认证后才能引用”的门槛。

另一记录只说“本次资料未附归档检查表”，可以说明本轮不能据表核查，不可改成“团队从未检查”。修复之后回读解释、影响与结尾：若还写“由于没有检查，下一步须先建立检查机制”，同一无据前提仍在生效。已能呈现的实际操作和成果继续写，不把整段内容削成免责说明。

归并思路的来源和研究限制见[阅读与摘要研究](method-sources/sources/reading-synthesis.txt)。它提供编辑启发，不是中文汇报或本Skill效果已获验证。
