# 概念与状态澄清

方法修订：0.9.0（2026-11-12）。

- **触发**：同一个“完成/进度/上线/价值”可能指不同对象、期间、分母或状态，差异会影响判断。词义已清楚或只是排版修改时跳过。
- **动作**：从材料列出本次问题涉及的对象、观察时点、比较参照、状态及计量口径。用两个边界例检验差异；保留资料原词和解释之间的对应。只定义本次需要的概念，不建设通用大本体。
- **可观察结果**：一段或小表写明原来混淆了什么、依据在哪、现在分别支持什么。例如“某范围开发完成80%”有明确分母时可以成立，却不自动支持“项目验收80%”；未验收也不反证前者虚报。假设例必须标成假设。
- **回落与停止**：把区别落实到标题、标签、分母、证据请求或结论强度；概念已足以指导本次取舍时停止。无法定义时请求原口径，不代作者补定义。
- **需挑战的地方**：实际表达对应哪个对象/状态，是否与资料一致？名称不同未必不同，名称相同未必同义；定义齐全不证明测量真实。

背景：[本地概念建模摘要](method-sources/sources/ontology-scope.txt)。专业进度判断需要领域资料时另走[知识目录](../knowledge/index.md)许可，不因读本卡自动获准。

本卡交回一个可用区别、修正判断或具体待核事项；不另启动成稿/验收流程。共用[含义保真标准](semantic-structuring.md#含义保真的共同标准)。

## 把操作落回判断

必要输入：当前主张、原句/记录版本、对象、时点及实际指标或授权口径；同词异义必须会改变本场判断才继续。

沿当前请求分别核“必要、经济、可承担、获授权”：它们回答不同条件，一项成立不能改名成为其他项。定义后用实际原句试回填，检查得到的判断是否与来源一致；假设边界例只检验概念，不成为项目实际反证。

合成例：“已有预算”只确认额度事实，尚需核用途、占用及本次谁批什么；不能据此称支用已获完整授权。误用：把所有“完成”统一改成同一状态，再用一致用词掩盖不同范围。 以上为合成教学例。

主Agent先用已有资料完成可做的分析，真正缺事实时说明具体最小输入/替代、它决定哪个判断和不补时的边界；不是让用户完成分析。所缺若为工具或专业能力，明示尚未完成的核验，不伪称只缺资料。产物是有依据的区别、判断或未决条件，落实到实际内容后停止。

挑战者只用方法形成目标相关问句；不把本卡操作清单或修复建议交给主Agent。审计仍检查依据、影响和修法；真实委派见[契约](agent-delegation.md)。
