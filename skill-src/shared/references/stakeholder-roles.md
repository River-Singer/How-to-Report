# 真实利益相关者与职责索引

用于帮助用户讲清本场角色、判断责任与方法入口，不是默认评委名单或人格prompt库。新的完整汇报在正式定叙事和挑战前，按[目标发现](goal-discovery.md)确认目的、场合及下列关系；已确认信息沿用，局部修改不重问。职位名只能提示可能职责，不能证明本企业授权、私人动机或实际关切。

## 从用户实际描述确认

先用现有议程、要求和对话，整理“谁代表什么、对什么结果负责、本场需判断什么”。若只知道“部门领导、科室领导、专家”，帮助用户补清：谁最终决定或评价，谁有正式否决/暂停/附条件同意权及范围，谁通过专业意见、资源控制或后续审批影响结果。没有正式否决者也可以明确；影响权不能写成否决权。姓名通常非必需，不收无关个人信息。

角色可兼任，决定者可不在场；区分本场能够得到的结果和仍需后续谁决定。职责明确不等于态度已知，不把财务设为永远少花钱、安全设为消除一切风险或用户设为拒绝改变。关键关系未知时继续整理事实和候选方向，但不虚构角色、不宣称正式叙事和相应挑战已经完成；沉默不算确认。

以下为职责发现线索，必须结合本组织和本场确认。按未解判断选少量相关方法，专业正文仍遵守已有授权，不因角色目录存在便读全库或创建全部角色。

| 职责线索 | 受托利益与本场可能判断 | 有用真实输入；按问题发现方法 |
|---|---|---|
| 最终决定/评价、项目治理 | 整体目的、资源取舍和可接受后果；本次究竟决定或评价什么 | 当前请求、选项后果、实际授权；[替代选择](../knowledge/bus-02-options.md) |
| 业务发起、收益负责人 | 交付是否改变实际工作、收益条件由谁落实 | 流程痛点、负责人、采纳安排；[价值链](../knowledge/bus-01-benefits-chain.md) |
| 战略、IT规划、组合管理 | 必要性、能力复用、优先级与整体资源利用 | 项目/能力清单、约束和优先级；[组合选择](../knowledge/or-03-portfolio-options.md) |
| 财务、预算管理 | 资金可承担性、额度与支用、持续支出和付款节奏 | 实际批复、申请口径、余额与付款；[费用结构](../knowledge/fin-03-cost-structure.md) |
| 采购、供应商管理 | 可比交付、付款验收、供应与替换条件 | 报价、服务期、排除项、合同和验收；[费用结构](../knowledge/fin-03-cost-structure.md) |
| 企业/解决方案架构 | 能力边界、复用集成、演进与退出 | 当前/目标范围、接口、依赖与约束；[系统边界](../knowledge/swe-03-system-boundary.md) |
| 基础设施、技术运维 | 容量、可靠性、支持负担与恢复 | 真实负载、环境、监测和恢复记录；[可靠性证据](../knowledge/swe-02-capability-reliability.md)，容量流动争点再用[瓶颈](../knowledge/or-02-bottleneck-flow.md) |
| 信息/网络安全 | 信息与业务的保密、完整、可用及真实暴露 | 数据流、字段、主体、边界与控制验证；[控制覆盖](../knowledge/sec-01-control-coverage.md) |
| 数据负责人、数据治理 | 数据含义、质量、适用性和变更责任 | 定义、来源、口径、质量与权责；[用途与责任](../knowledge/data-03-purpose-accountability.md) |
| 隐私/个人信息职责 | 处理必要性、对人的影响和生命周期责任 | 字段用途、处理方、留存删除、实际适用条件；[用途与责任](../knowledge/data-03-purpose-accountability.md) |
| 法务、合规 | 适用义务、合同责任、授权及承诺边界 | 实际条款/规则、已有意见与批准；[条件推理](method-conditions.md)，不代作法律认定 |
| 风险、内部控制 | 控制和风险接受责任与实际组织边界相符 | 风险标准、控制证据、授权；[依赖与风险](../knowledge/pm-02-dependencies-risk.md)及[条件推理](method-conditions.md)，安全控制争点再用[控制覆盖](../knowledge/sec-01-control-coverage.md) |
| 企业内部审计、独立保证 | 决策和控制依据可核实、保持职责独立 | 相关批准、变更、验收版本和审计范围；[论证](method-argument.md)；不是本Skill的独立审稿Agent |
| 项目/项目群、PMO | 交付、依赖、变更与资源承诺可行 | 剩余任务、基线、技能、实际时段；[资源可行性](../knowledge/or-01-feasibility.md) |
| 流程负责人、一线使用者 | 任务与例外能完成、工作负担和责任不被隐藏转移 | 真实流程、例外、分工与反馈；[瓶颈与流动](../knowledge/or-02-bottleneck-flow.md) |
| 人力、能力建设、变更采纳 | 技能、人员可用性、职责转变与持续采用 | 技能/可用时间、职责和实践记录；[资源可行性](../knowledge/or-01-feasibility.md) |
| 质量、测试、验收 | 是否满足约定用途、接收决定有据 | 验收版本、测试条件、结果和接收权责；[交付与验收](../knowledge/pm-01-delivery-status.md)及[可靠性证据](../knowledge/swe-02-capability-reliability.md) |
| 生产/服务运营、连续性 | 业务接续、异常处理和持续运行 | 业务影响、切换回退、承接及验证记录；[依赖与风险](../knowledge/pm-02-dependencies-risk.md)及[可靠性证据](../knowledge/swe-02-capability-reliability.md) |
| 技术实现、研发 | 能力可实现、开发集成与维护承诺有据 | 实现/验证范围、版本、依赖和能力；[能力证据](../knowledge/swe-02-capability-reliability.md)，范围/链路不明再用[系统边界](../knowledge/swe-03-system-boundary.md) |
| 市场研究、市场策略 | 选择有证据的目标市场、需求和可达机会 | 研究对象、样本、期间、替代与服务约束；[市场证据](../knowledge/mkt-02-market-evidence.md) |
| 产品营销、营销管理 | 为谁提供何种相对价值、投入与采用效果 | 实际替代、差异证据、渠道/活动目标和结果；[定位与价值](../knowledge/mkt-03-positioning-value.md)及[采用成效](../knowledge/mkt-01-user-adoption.md) |
| 销售、客户经营 | 具体客户购买条件、可兑现承诺与机会推进 | 买方实际问题、角色/条件、行动及下一步；[购买条件](../knowledge/sls-01-buying-conditions.md) |
| 公关、企业传播 | 消息可信、相关公众理解、关系和声誉 | 真实受众、目标、消息权限、反馈和结果；[传播效果](../knowledge/com-02-communication-effects.md) |
| 真实客户、合作方、受影响公众代表 | 自身任务、承诺履行及方案带来的实际影响 | 本次关系、代表范围、采用/合作条件、真实反馈；按问题用[购买条件](../knowledge/sls-01-buying-conditions.md)或[消息边界](../knowledge/com-01-message-risk.md) |
| 真实媒体、行业交流者、技术同行或评委 | 对其受众负责的信息、专业判断或已确认评价职责 | 实际参与身份、评价标准、公开范围及可核实成果；[消息边界](../knowledge/com-01-message-risk.md)及[论证](method-argument.md) |

外部参与者只有用户确认实际存在及其关系后才采用；不因“对外汇报”自动创建记者、公众或评委，也不赋公司审批权。技术运维与业务连续性、数据治理与隐私、安全控制与所有风险管理分别核实际职责，不能仅因同属一部门便混成一种判断。

## 从职责转到本次问题

按“受托利益 → 本场判断 → 当前请求的必要前提 → 当前资料”寻找相关断点，执行交[定向挑战](directed-challenge.md)。同一个职能在立项和成果展示中可能承担不同判断；成果展示不因为有PMO就强加无关进度问责。专业知识是判断工具，不反过来替用户生成参会身份。

市场选择、产品定位、营销活动效果、销售机会、公关理解或关系目标不是统一转化漏斗；汇报人的岗位也不直接决定本次目的。对外建立本人价值与专业认可是一种经用户确认的目标，用[论证中的个人价值构思](method-argument.md)连清能力、实际判断/行动、协作归属和听众用途，不另设“个人营销部门”或人格Agent。用户只要客观信息时不强加个人展示。

不同职责可能提出同时合理的约束，例如共用平台节约资源却改变数据边界和集中故障影响。主 Agent比较同一组实际选项、证据与后果，保留需要有权者决定的取舍；不猜部门私利，不按人数或职级投票，也不要求所有角色满意才结束。
