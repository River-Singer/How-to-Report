# 让候选价值成为有依据的判断

方法修订：0.9.0（2026-11-12）。

在已有事实之上建立解释、用途、贡献或推荐时使用；也用于修复功能、投入直接跃迁成效果或承诺的断点。本卡承担主流程B中的论证，不另定义生产步骤。

先明确准备让听众理解什么，以及它对本次任务有什么用，再接上资料到判断之间的桥梁。已有能力怎样作用于具体工作？观察到的变化支持哪种解释？汇报者实际识别、选择或推动了哪一步，合作者承担什么？对这些关系找支持、反证、替代解释和关键条件；不要求把同一组框填满。

价值停在资料支持的层次：能定位原记录，可以解释怎样帮助核对；缺工时数据不妨碍用途说明，也不支持已节省工时。需要推荐时，比较选项对同一目标的差别，再核实际采用的理由。某项有业务核对安排，可以据此推荐，不能接着补“成本最低、机会仅此一次、其他随时可做”。推荐合理不替这些新断言提供证据；更多理由有新增解释或区分才保留，重要反证仍须讲。关键未知会改排序时，指出具体核实问题，不硬排也不把所有方向平铺成同等值得试。

个人贡献沿“当前发言人—实际行动—对过程或结果的作用”核对。画出或修改协作图，支持这项表达工作，不自动证明设计并管理了图中机制。已记录的判断与协作可以正面表达，无需先有量化收益；代表团队不拥有全部成果，模型新建议不变某人的历史成绩。希望得到认可决定内容重点，不证明听众已经或必会认可。

对重要推断问：下层事实都成立，上层判断是否仍可能缺条件？找到缺口后，补支持、收窄主张或形成条件建议。必要条件与充分条件分别核查，关系类比不能替代项目证据；资料不足不推出项目未开展。具体标准共用[含义保真](semantic-structuring.md#含义保真的共同标准)，新增区别由[解释探索](insight-discovery.md)处理。

交回可用的判断、依据和必要条件，或最能改变选择的待核事项。下一步需要事实就停止自我论证；不把每项候选和检验搬进正文。遗漏的重要性取决于本次任务，不能用未选的每一种角度否定已有合理材料。

背景：[论证方法摘要](method-sources/sources/toulmin.txt)、[受众价值与贡献研究札记](method-sources/sources/audience-value-contribution.txt)。它们提供方法启发，不是项目证据或Skill效果认证。


## 正向构思个人价值与可信责任

必要输入是本场目的、实际受众要判断的任务、当前发言人的相关经历/作品/判断行动、合作分工及记录。用户明示争取专业认可、合作或后续责任时积极采用，不再次盘问隐秘动机；用户只要客观情况或明确否认个人展示时，不暗中优化个人推销。

从“这位受众为什么愿意信任我承担什么”选择少量相关能力，再从记录找到真实事件：当时难在哪里、有哪些可选做法、我作了什么判断/行动、对过程或结果起了什么作用。不是先写“善于创新”再为品质找包装；也不必等有精确ROI才表达判断价值。

把能力连到受众用途和迁移条件。相似任务中的成功可以支持有限可承担范围，不能推出任何行业都能交付。具体区分本人、团队、外包和工具的工作及验证责任，正面展示有据的本人作用，不冒领团队成果，也不以机械感谢替代归属说明。第三方评价有来源和适用范围，不能虚构背书。

最后给与目标及证据相称的下一步：合作目标可提出有边界的试用/讨论或责任范围；仅要成果认可就完成评价依据。推荐是未来安排，不改成过去功劳。检查所承诺能力和权限，没有安排不代别人许诺。

合成应用：本人识别两部门成本定义分歧，整理并主持核对12项定义；业务负责人确认，开发同事实现接口，三个样本可复算。可写：“我能把跨部门口径分歧整理成可验证规则。本次我整理并组织核对12项定义，业务完成确认，开发完成接口；目前三个样本按同一口径复算。若开展小范围试用，我可以负责需求与验证规则，数据接入和签收需双方确认。”这展示了动作、作用与合作价值，尚不声称全量降本。

误用对照：“我独立建成成熟体系、显著提升全公司效率”超出上述范围与归属；反过来只写“参与过项目、可能有一点帮助”也抹掉了已证判断。若目标只是客观统计复盘，保留事实及机制即可，不强加第一人称定位或合作邀请。

## 论证、阻断与停止

论证的强度来自证据与推断。对重要主张检查支持前提、关系桥梁、反证和适用条件；最强相关异议要能说明为何现有依据仍不足以达到确认目标，以及什么事实会使它失效。不能以外部文献权威或一般心理规律替代本次反证；推翻一个次要理由不等于推翻结论。逻辑反例只检验充分性，未核实不能写成项目事实。

主Agent完成现有资料可做的查算；真正缺事实则明确索取最小记录/可接受口头说明及其用途，保留未决条件，不能用漂亮表达绕过。反证到来时实际修改主张、推荐或范围；有据内容保留。交回可读的概要、解释和必要限定，不交全部思考过程，关键关系明确后停止。

挑战者用同一知识，只返回仍成立的目标相关问句，不给修法或参考答案；独立审计按真实成稿/来源判断，其意见格式不受问句限制。执行角色、复查及空集合边界见[委派契约](agent-delegation.md)与[定向挑战](directed-challenge.md)。
