# 发现并操作化汇报目标

用于目标含糊、材料揭示新机会、受众/要求改变或原目标前提受挑战时。明确的局部修改可沿用现有目标。这里提供认知操作，不要求每次填表或再确认已授权事项；审计时用它重建与核对目标，不替用户重新定目标。

## 建立当前情境

从已授权的要求、议程、评价标准和材料取得：为何此刻汇报、必须回答什么、参与者已知/未知/有何分歧、谁能决定或影响什么、近期变化和时间约束。给影响主线的条件保留出处；材料没有说明的认知、权责或意图保持未知。职位和画像不能直接证明当前受众偏好。主体是能够理解、决定或行动的人与组织；项目是带有目标、状态和约束的事项，不把它拟人成“想要”某个结果。用角色—动作—参照对象—条件描述关系；不预设参与者利益冲突，也不默认所有人都想恢复旧计划。

把下列来源分开，不合并成一个“目标已确认”标签：

- 正式要求与用户已表达的目标：当前采用的起点，仍须澄清笼统含义和事实前提。
- 尚未表达诉求的假设：有线索但未确认的意图，不当作用户事实。
- 新目标建议：材料显示值得追求的沟通效果，不声称用户原本就想如此。
- 项目结果与收益：需要实际实现条件和观测，不能由一场汇报或用户选中目标来保证。

潜在效果不等于个人动机。只有与当前任务有关的线索或用户表达支持时，才提出具体诉求假设；不例行猜测晋升、政治或他人心理。用户否定后停止沿用，不在内容取舍中暗中继续优化该诉求。信息同步、客观复盘、学习、重定基线或停止某项工作都可以是合理目标，不强行转为财务、审批、能力展示或恢复旧计划。用户希望体现能力时，仍只能展示有材料支持的判断与行动；没有方案证据就不编造已有方案。

## 两个方向寻找候选

**从材料正推：** 找变化、异常、矛盾、依赖、限制、可复用关系和机会，连接“它对这些参与者意味着什么”与“此次沟通能使什么理解、判断或协作发生变化”。检查不讲清楚可能造成的误解、错过的窗口或未处理的正式问题。先允许新方向出现，不把探索范围提前锁死在旧主线。

**从可能效果反推：** 对候选问：听众会后需要比现在多理解什么、能区分什么、能作什么判断或行动？为此必须回答哪些问题、成立哪些判断、取得哪些证据或授权？把会场内可实现的效果与后续依赖他人的结果分开。

遇到手段与目的混淆时作有边界的反问：即使完成这份产物或取得这个动作，原来的困难是否仍存在？即使候选目标实现，它为何对这次沟通重要？沿实际任务追到能指导取舍的层次即可，不追溯到臆测的人生目标。

候选保留有用差异。不同说法若要求相同判断、证据和行动，合并；同一目标的前置条件、辅助目标和竞争目标标明关系，不假装相互独立。必要时用 [解释探索](insight-discovery.md) 研究新问题表示，再带回候选目标。

## 评估与选择

对会改变方案的候选检查：

| 检查 | 实际动作 |
|---|---|
| 来源与归属 | 说明来自正式要求、用户表达、材料推导还是意图假设；保留定位和未知 |
| 前提 | 找出目标隐含的事实主张，核对支持与反证；希望证明某结果不使结果预先成立 |
| 可达性 | 核实参与者权责、时间和依赖；权限不足时提出可行的说明、征求意见或转交路径，不伪造授权 |
| 主次与冲突 | 比较它会增加/舍弃的内容、证据和时间；保留正式必答和重要风险，不默认业务价值最高或自动加权选赢家 |
| 可操作性 | 能否导出明确受众问题、判断和内容职责；只有“展现价值”等标签时继续澄清 |

在写大纲前做一次可观察的差异检查：当前少量候选结果会不会实质改变必需证据、内容结构或结尾动作？若只是换标题则合并；若差异会改变方案而尚无选择，先从已有材料尽量确定，再用中性问题澄清关键未知，例如“此次会议结束时最需要形成什么结果”。不要暗示对方应该争资源、证明能力或接受某个目标。可从2–4个有依据的候选结果起步，但这是可调的工作起点，不是固定配额；已有清楚目标时可只有一个。

已有明确选择或授权可直接采用，不反复问已确认目标。重大主线扩张、冲突取舍或未确认诉求需要用户选择时，给简短候选策略和具体差异；不要把整套分析清单交给用户填写。可用简洁结构图展示中心问题、模块关系、重点和缺口。

等待回答时继续各候选共有的资料核对或可逆草稿，明确采用的临时假设；未答复不是确认。用户授权代选方案时可以在范围内推荐并说明依据，仍不能称潜在动机得到确认。新证据与新要求可以重开选择；不得静默换题。

## 进入内容并保留反馈

当前采用的目标应说明：面向谁、希望其理解/判断/行动发生什么变化、为何此刻重要、不可丢的要求与事实边界、什么可观察现象能帮助检查效果。没有会后观测时，只能评价产物是否支持目标，不能宣称听众已经理解或同意。

为目标导出必答问题，再为每个问题准备完整判断、依据、限定或未决项。进入 Blueprint 时标明每块内容服务哪个问题；不把目标只放在首页而继续沿用旧目录。缺证只转成必要的调查/计算/澄清任务；任务完成后另行判断其结果能否支持主张。

在 Run 的可定位笔记中记录必要的“目标候选 → 来源/前提 → 当前取舍及理由 → 内容与证据需求变化”。只保留可审阅决定和依据摘要，不记录私有推理过程。短任务可以一段完成。

Goal 被采用、Claim 被核验、Task 已完成、沟通效果发生互不替代。选择写在目标决定中，不用证据 `verified` 表示“用户选了这个目标”。需要机器查询目标变更影响时，把目标说明登记为版本化产物，让相关内容以 `uses` 引用该版本；单有 `notes_ref` 不会自动产生依赖传播。其余情形人工说明影响范围，不宣称自动失效。

停止探索的条件是当前正式问题与重要取舍已能指导内容，剩余未知已明确且不会被冒充结论；不是候选达到某个数量。交付可继续讨论的策略/Blueprint，不承诺穷尽所有潜在目标。
