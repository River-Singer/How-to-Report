# 审计工作区说明

本文件由初始化模板创建。当前身份、精确目标版本和状态以同目录的 `run.json` 为准。
目标是审阅登记的报告并单独保存审计结果；本工作区不授权修改原报告。

初始化只建立记录。若使用 `audit_run.py init`，脚本会读取目标字节以计算指纹；
若手动复制模板，不代表脚本已运行或指纹已计算。两者都不表示审计者已阅读、理解或核验内容。
尚未登记实际来源阅读、上下文继承、生成计划暴露或数值复核方式，不能据此声称独立审计。
在真实审计过程中补充本次要求、范围、可得来源、执行与不能评估的限制。

完成审查后，以最新工作状态和结论替换本文件中的初始化说明；与 `audit.md` 当前摘要及
`run.json` 的目标、检查方法/范围/状态保持一致。后补证据和撤回理由在审计报告的历史章节保存，
不能让旧结论继续作为当前摘要。撤回错误指控不表示未评估主张已通过。

当前缺陷、必要证据缺口和可选建议分开说明与计数；可选建议不计入缺陷，也不单凭建议决定 conditional。
实际计算的原始输出与整理说明分别标明位置和身份；没有原始凭据时如实披露，不由整理表反推历史执行。

交付前对本工作区执行 `audit_run.py check`。结果只说明结构与声明引用是否一致；
不会把未执行的内容检查改成通过，也不会自动完成审计。自动检查未执行时，应明确披露。
